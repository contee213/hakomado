📖 使い方

YouTube・Twitch の配信を最大 16 枠に並べて、同時に見られます。

  • 空き枠に URL (YouTube・Twitch) / 動画 ID / @チャンネル名 を貼って「読み込む」。今の配信は「📺 チャンネルから選ぶ」、終わった配信は「📚 ライブラリから選ぶ」、「🎲 おまかせ」はまだ出ていない配信を 1 本入れます
  • YouTube の動画・配信や Twitch のチャンネル・VOD へのリンクを右クリック →「Hakomado の空き枠に追加」でも入れられます
  • 音は、ふつうは 1 つの枠からだけ出ます。枠のバーの 🎧 か 1〜9 で切り替えます。ℹ️ 枠の情報の 🔊 か、枠の中のプレイヤーのスピーカーで音を出すと、複数の枠を同時に聞けます
  • 画面を一通り見るには、下の「使い方ツアーをもう一度見る」をどうぞ
  • 上のバーの「▦」でレイアウトを選びます。濃い枠がメインで、読み込んだ配信は 1 番 (メイン) から順に入ります。「＋」「−」で枠を増やす・減らす
  • 配信の入った枠にマウスを乗せると、操作バーが出ます。左端の ⠿ をドラッグすると、枠を入れ替えます (音が出ている枠は Shift + 矢印キーでも動かせます)
  • 枠のバー: 音のボタン (この枠の音を出す) / 🎚 音の左右・音量・遅延 / 1× 再生速度 / 💬 チャット欄 / ≋ 弾幕 / 🔖 あとで見る / 👍 高評価 / ⟳ 読み込み直し / ⛶ その枠だけ全画面 / ✕ 閉じる
  • 「ℹ️ 枠の情報」(I) の各行: 音の左右 (L / C / R) / 📌 ピックアップ / 🔖 あとで見る / 📃 再生リストに入れる / チャンネル登録 / 👍 高評価。タイトルを押すと、その動画を YouTube の新しいタブで開きます
  • 🎚 では、その枠の音を左・真ん中・右から聞こえるようにしたり、音量 (0〜200%) を変えたりできます。左右は「ℹ️ 枠の情報」の L / C / R でも変えられます。ライブ配信では「音の遅延」で、その枠の音だけを遅らせられます (映像はそのまま。コラボで、ほかの枠より声が先に聞こえるときに)
  • 「⛶」(Shift + F) で、分割したまま全画面にします。上端にマウスを寄せるとバーが出ます
  • 「🔁 繰り返し」(R) を ON にすると、全部の枠の動画・アーカイブが最後まで行ったら最初から再生し直します (ライブ配信と、自動再生・あとで見るの順の再生で次を入れる枠は除く)
  • 「ℹ️」(I) で、各枠の種類 (ライブ・アーカイブ・動画)・配信の時間・今の視聴者数・再生数・アーカイブ同期できるかを一覧で見られます

「自動再生」(L) を ON にすると、配信中のチャンネルを全部並べます。その後も 1 分ごとに、始まった配信の枠を足し、終わった配信の枠を消します。

  • ON にするとき、自分で入れた枠が置き換わるなら、先に確かめます
  • ON の間に ✕ で閉じた配信は、入れ直しません (OFF → ON で戻ります)。自分で入れた枠は消しません

設定 → 自動再生

  • 自動再生対象: 配信中・動画・ショートから選びます (1 つ以上)。動画・ショートは、チャンネルの最近 30 日のものを新しい順に流し、最後まで見た枠には次が入ります (ピックアップが先、一度見たものは除く)。配信と一緒に選ぶと、配信を先に入れて、最大枠数までの空きを動画・ショートで埋めます
  • 自動再生のチャンネル: すべてのチャンネルか、ピックアップ (📌) だけか
  • プレミア公開の動画・ショートも配信として扱う: 時間指定で公開される動画・ショートも、配信と同じように枠に入れて知らせるか。外すと公開予定の確認が減って軽くなります
  • メンバーになっていないメンバー限定配信は再生しない: ログイン中のアカウントで見られるかを、枠に入れる前に確かめます
  • 自動再生の最大枠数: 配信中のものが多くても、この数までしか再生しません。増やすと、すぐに空いた分を足します (減らしても、表示中の枠は消さず、終わったものから減っていきます)。回線が細いときや、パソコンが重いときは減らしてください
  • ピックアップ (📌) の配信をメイン枠に優先して置く: ピックアップのライブ配信を大きいメイン枠に入れ、ほかはサブ枠に回します。最大枠数に届いたときも、ピックアップを先に入れます。メイン枠の無い均等レイアウトと、クルーズ中は並べ替えません
  • 配信予定の枠を用意する: 開始前から枠を作り、最初から見られるようにします。配信中のものが 1 つも無いときは、次に始まる配信予定と、その開始から 1 時間以内に始まる予定を出します
  • 配信中が無いときは、最近の動画を流す: 深夜などライブが 1 本も無いときに、チャンネルの最近終わった配信や公開された動画を 4 枠流します (ピックアップが先、一度見たものは除く。動画・ショートも流すかは設定で選べます)。ライブが始まったら片付けます

「クルーズ」(C) を ON にすると、一定の間隔でメイン枠と音声を次の配信へ回し、いろいろな配信を少しずつ見られます。自動再生を使わず、自分で並べた枠でも使えます。

  • 間隔は 設定 → 自動再生 →「クルーズの間隔」で変えます
  • 均等レイアウトでは並びはそのままで、音声だけ次の枠へ移ります。空き枠は回さず、レイアウトも変えません
  • 自動再生で枠を組み替えるときは、「メイン + サブ」のレイアウトを優先します
  • 「📺 チャンネル」(F) で、追加したチャンネルの配信中・配信予定と、それ以外を一覧します。配信中・予定の行を押すと、空いている枠に入ります
  • 行の「最近 ⌄」でそのチャンネルの最近の動画を開き、📌 でピックアップに入れます
  • ピックアップ: 今注目しているチャンネル (箱企画の参加者など)。上の「📺 すべて / 📌 ピックアップ」で一覧を絞れて、自動再生や通知の対象にもできます
  • 🔔 通知: チャンネルの配信が始まると知らせます。どのチャンネルを知らせるかは 設定 → 自動再生 →「通知のチャンネル」で選びます

チャンネルの管理

  • 「📺 チャンネル」の「⚙ 管理」か、設定 → チャンネル から開きます。チャンネルを足す・外すのはこの画面で行います (配信を探している途中に、間違えて外さないように)
  • 下の欄に @チャンネル名・チャンネルの URL・動画の URL を入れると追加できます
  • 外す: 外したいチャンネルの ☐ に印を付けて (「表示中をすべて選ぶ」も使えます)、「選んだチャンネルを外す」を押します。確かめるのはまとめて 1 回です。📌 付きのチャンネルは、「📌 付きも外す」に印を付けない限り残します。外した同梱のチャンネルは「戻す」で戻せます。ほかのチャンネルは、足し直せば戻ります
  • チャンネルパックは、チャンネルの一覧をまとめたものです。ホロライブ (同梱版) は最初から入っています。パックごとに、まとめて外したり戻したりできます。自分で追加したチャンネルと、ピックアップに入れたチャンネルは外しません
  • パックを探す: Hakomado のリポジトリ (GitHub) に集めたパックの一覧から選べます。利用者が作って投稿した非公式のもので、各事務所・配信者とは関係ありません。誤りや追加の希望は GitHub で知らせてください
  • チャンネルパックを読み込む: ほかの人が作ったパックの URL か中身を貼るか、ファイルを選んで足します。登録済みのチャンネルはそのままです
  • チャンネルパックを書き出す: 同梱のホロライブ・読み込んだパック・自分で追加したチャンネル・すべてから選んでパック (JSON) にし、ほかの人に配ったり公開したりできます
  • YouTube の登録チャンネル: ブラウザでログインしている YouTube アカウントの登録チャンネルを読み、選んだものだけを足します。足したチャンネルはパック「YouTube の登録チャンネル」にまとまるので、まとめて外せます。アドオン「YouTube の登録チャンネル」が ON なら、多く足しても配信状況の確認が追いつくようにしています

設定 → アドオン

  • アドオンは、特定のサイトに頼る機能です。1 つずつ ON / OFF できます。ON にするとき、そのサイトへのアクセスの許可を求めることがあります
  • ホロジュール (初期値は ON): ホロライブの配信予定 (schedule.hololive.tv) をまとめて読み込み、初期データのチャンネルと、ホロライブのチャンネルパックから足したチャンネルを YouTube に確かめに行く回数を減らします。OFF でも、各チャンネルの RSS から配信状況を調べます (少し重くなります)
  • にじさんじ (初期値は OFF): にじさんじ公式サイトのライブスケジュール (www.nijisanji.jp) を読み込みます。名前に「にじさんじ」が入るチャンネルパック (「パックを探す」の「にじさんじ」など) から足したチャンネルは、YouTube に確かめに行く回数を減らします。ON にするとき、www.nijisanji.jp へのアクセスの許可を求めます
  • ぶいすぽっ! (初期値は OFF): ぶいすぽっ!の配信スケジュール (有志による非公式のサイト www.vspo-schedule.com) を読み込みます。名前に「ぶいすぽ」が入るチャンネルパック (「パックを探す」の「ぶいすぽっ!」など) から足したチャンネルは、YouTube に確かめに行く回数を減らします。ON にするとき、www.vspo-schedule.com へのアクセスの許可を求めます
  • STPR (すとぷり) (初期値は OFF): STPR の公式の配信予定 (schedule.stpr.com。データは schedule-share-json.s3.ap-northeast-1.amazonaws.com から読みます) を読み込みます。名前に「STPR」か「すとぷり」が入るチャンネルパック (「パックを探す」の「STPR (すとぷり)」など) から足したチャンネルは、YouTube に確かめに行く回数を減らします。ON にするとき、schedule-share-json.s3.ap-northeast-1.amazonaws.com へのアクセスの許可を求めます
  • YouTube の登録チャンネル (初期値は ON): ログイン中の YouTube アカウントの登録チャンネルのフィードを 2 分に 1 回まで読み込み、配信中・配信予定をまとめて知ります。「登録チャンネルから選ぶ」で足したチャンネルは、YouTube に確かめに行く回数を減らします (数百件あっても確認が追いつくように)。そのチャンネルが 1 つも無いときは読み込みません
  • 「📚 ライブラリ」(B): 🎞 最近の動画 (最近 7 日に終わった配信と、公開された動画) / 🕘 視聴履歴 (100 件) / 🔖 あとで見る (100 件) / 📃 再生リスト
  • 種類の絞り込み: 一覧の上の「🔴 配信 / 🎬 動画 / 📱 ショート」で、出す種類を選べます (いくつでも。最近の動画・視聴履歴・あとで見るで共通)
  • あとで見る: 枠のバーや一覧の 🔖 で入れます。「▶ 今の枠で順に再生」で今ある枠に順に入れ、最後まで見た枠には次が入ります。最後まで見たものは消えます
  • 再生リスト: 名前を付けた並び (30 個・1 つに 200 本まで)。「＋ 新規」「▦ 今の枠から作る」「📥 読み込む」で作り、URL の欄や、「ℹ️ 枠の情報」・一覧の 📃 で足します。⠿ で並べ替え、行の名前は枠に出す名前になります
  • Twitch のライブ: 共有・あとで見る・再生リストに入れると、その配信の録画 (VOD) になります。後から開いても同じ配信を最初から見られます。チャンネルが録画を残さない設定のときは入れられません (共有ではチャンネルのままになり、後から開くとそのときの配信になります)
  • 「▶ 順に再生」は今の枠に上から入れて、見終わった枠に次を入れます (最後まで見たものに ✓ を付け、次は続きから)。「⏱ まとめて同期再生」は全部を一度に並べて、アーカイブを同じ瞬間にそろえます (16 本まで)
  • 上のバーの「⏱ アーカイブ同期」を押すと、配信の時間帯が重なるアーカイブを、配信していた実際の時刻でそろえて再生します。アーカイブが 2 本そろっていないときは薄く出ていて、押すと使えない理由 (ライブ配信中・ふつうの動画など) が出ます
  • 時間帯が重なるアーカイブどうしを自動でグループにまとめるので、別々のコラボの A・B と C・D を別々にそろえられます (4 組まで。枠に色と番号が出ます)。グループは同期の調整パネルの各行で付け替えられます
  • 同期の調整パネル (上のバーの ☰) は、枠の上に浮かぶ半透明の小窓で出ます (見出しをつかんで動かせます。⇲ で画面の右の列にもできます)。グループごとに、そろえ方 (🕒 コラボ配信 / 🎬 同時視聴)・⏸・✨ 自動補正・つまみ、枠ごとに、基準 (🔒。🎬 同時視聴のグループでは ◉)・補正・⏸ 止めて待つ があります。グループごとの図は、各枠の開始のあたりを拡大したものです (開始どうしが 1 分より離れていれば、間を詰めて棒に切れ目を入れます。上に各枠の開始の時刻を出せるだけ出します)。横棒は配信の実際の開始から右へ続き、補正の分は水色で出ます (早めたか遅らせたかは、細い線との位置で分かります)。出す位置は基準と一緒に流れ始めるところ (基準より前に始まった枠は基準の開始) で、細い線が補正を入れる前の位置です。そのとき既に流れているほかの枠の行にも同じ時刻に細い線が出るので、見比べられます。基準との開始の差と、設定の位置まであと何秒かも出ます。調整しないグループは ▾ でたためます
  • ✨ 自動補正は、グループの枠の音 (コラボの通話の声) を最大 180 秒聞いて、各枠の補正を求めます。35 秒を過ぎると、枠ごとにここまでで一番よかった値が途中の結果として出ます。どの枠も ◎ になったら切り上げを提案するので「ここで決める」で終えられ、180 秒まで聞いたときは一番よかった値を採ります。結果は各行の「✨ −1.61 ◎」と図の ◆ (反映したあとの位置) で確かめてから「反映」します。◎ 確か / ○ たぶん / △ 怪しい。決まらなかったり △ が多ければ、話している場面で「測り直す」を押してください
  • 🕒 コラボ配信は、同じ時間に配信していた各視点を、配信していた時刻でそろえます。🎬 同時視聴は、同じ本編を見ていた配信を、本編の同じ場面でそろえます (時間のずれた配信も。グループの見出しで切り替え)。🎬 同時視聴にすると、本編 (プレミア公開) の枠 (行に「🎬 本編」) の 0:00 が本編 0:00 で、ほかの枠の本編の位置は配信の時刻から見当を付けます。各枠の本編の位置は、同時視聴の配信のタイマーなどを見て「⏲ 画面タイマー」で決めます (0.01 秒単位。✨ 自動補正はコラボ配信だけです。同時視聴の配信には本編の音が入っていないことが多いため)。本編の枠が無いときは、各枠で「🚩 開始位置」か「⏲ 画面タイマー」で決めます。プレミア公開でない本編 (ライブのアーカイブなど) は、🎬 同時視聴のときに行の 🎬 で本編にできます。どのグループにも入らない、別の日の配信も、🎬 同時視聴の本編のグループに入ります。同時視聴の配信のタイマーなどを見て「⏲ 画面タイマー」に入れると、欄を押した瞬間の位置で決まります (欄を押している間は、その枠を同期から外すので、タイマーが見える所まで枠の中で動かせます)。同じ時間に配信していた枠どうしは、片方の本編の位置が決まると、もう片方の見当 (行に「≈」) も付きます
  • 合わせるのは基準でない枠です。基準の枠 (行の頭が 🔒) の補正はいつも 0 で、基準を変えると、そろい方はそのままで補正をほかの枠に移します。補正は −0.1・−0.01・+0.01・+0.1 のボタンで動かし、押し続けると続けて動きます。⏸ はこの枠だけ止めて待ち、▶ でそこに合わせます。行を選んで ← → でも補正を 0.1 秒ずつ動かせます (Shift で 0.01 秒)。行の ✓ は設定した補正どおりの位置で再生中、↻ はその位置へ寄せている途中です (声が合っているかは、聞いて確かめます)。手で合わせてうまくいかなかったときは、行の ↺ (グループ全部なら見出しの ↺) で実際の時刻に戻せます。補正は動画ごとに覚え、再生リストや共有するコードにも入ります
  • 上のバーのつまみは、音を出している枠のグループを動かします
  • 再生速度: 同期しているグループの枠は、1 枠だけでは速度を変えられません。グループのどの枠で変えても (枠の 1× ボタン・< > キー・プレイヤーの ⚙)、グループ全部の速度になり、同期の時計もその速さで進みます。ライブ配信の入ったグループは等速のままです
  • 基準の選び方: 主に音を聞く枠を基準にすると、その音がいちばん自然に聞こえます (ほかの枠は合わせるために少し速さを変えたり飛んだりします)。1 本だけ補正が大きくなる枠があれば、その枠は基準にしないほうが、ほかの動画の補正が小さく済みます (補正は動画ごとに覚えるので、ほかの組み合わせでもそのまま使えます)

「🔗 共有」と「📥 読み込む」は同じ画面で、上の切り替えで行き来できます。「🔗 共有」で、今の枠か再生リストを選んで、渡す相手に合わせた 3 つの形式にできます。

  • 画像: X などに添えて見せます。QR を読むと YouTube で開け、Hakomado では同じ並びで開けます。画像に付ける説明 (ALT) の文もコピーできます。「𝕏 に投稿」で、画像・名前・リンクを入れた X の投稿画面を開きます (投稿ボタンは自分で押します。初めてのときは x.com へのアクセスの許可を聞きます)
  • リンク: DM などで直接送ります。中身は画像の QR と同じ (16 本まで・レイアウト・補正・名前)。Hakomado が入っていれば開くだけで同じ並びになり、入っていない人も YouTube の再生リストとして見られます
  • テキスト: 1 行に 1 本。名前・同期・レイアウト・補正・枠の名前まで全部入ります (17 本以上の再生リストもこれで)。AI チャットに渡して直してもらうこともできます

「📮 サイトに投稿」で、Hakomado のサイトの投稿画面をこのセットを入れた状態で開きます (X でログインして、投稿ボタンは自分で押します)。

受け取ったものは「📥 読み込む」に貼ります (画像はドロップでも。入力欄の外で Ctrl + V しても開きます)。読み取った内容を確かめて、「▦ 枠に並べる」か「📃 再生リストとして保存」を選びます。取り込み用リンクを開いたときもここに来ます。

  • 弾幕: 各枠のライブチャットを画面に流します。枠の ≋ で枠ごとに ON / OFF (決めていなければメイン枠だけ)。D で全部を一時的に消せます。文字の大きさ・速さ・行数などは 設定 → 弾幕
  • チャット欄: 枠の 💬 で開きます。幅・文字の大きさ・アイコンを隠すかは 設定 → チャット欄 (開いているチャット欄にすぐ反映)
  • 枠の線: 音が出ている枠と、ライブ配信中の枠に付ける線の見た目 (両方のときは音の線が優先)。設定 → 枠の線
  • 設定・チャンネル (ピックアップを含む)・視聴履歴・あとで見る・再生リスト・表示言語を、1 つのファイルに書き出します
  • 拡張機能を削除して入れ直したり、別の版 (開発用のフォルダ・ID を固定する前の版) に切り替えたりすると、保存した内容は引き継がれません。その前に書き出しておき、あとで読み込んで戻してください
  • 読み込むと、今の設定・チャンネル・視聴履歴・あとで見るは、ファイルの内容に置き換わります。いま枠に入っている配信はそのままです
