      ? 使い方

      YouTube の配信を最大 16 枠に並べて、同時に見られます。

      • 空き枠に URL / 動画 ID / @チャンネル名 を貼って「読み込む」。今の配信は「📺 チャンネルから選ぶ」、終わった配信は「📚 ライブラリから選ぶ」、「🎲 おまかせ」はまだ出ていない配信を 1 本入れます
      • YouTube の動画・配信へのリンクを右クリック →「Hakomado の空き枠に追加」でも入れられます
      • 音は、ふつうは 1 つの枠からだけ出ます。枠のバーの音のボタンか 1〜9 で切り替えます。枠の中のプレイヤーのスピーカーで音を出すと、複数の枠を同時に聞けます
      • 画面を一通り見るには、下の「▶ 使い方ツアーをもう一度見る」をどうぞ
      • 上のバーの「▦」でレイアウトを選びます。濃い枠がメインで、読み込んだ配信は 1 番 (メイン) から順に入ります。「＋」「−」で枠を増やす・減らす
      • 配信の入った枠にマウスを乗せると、操作バーが出ます。左端の ⠿ をドラッグすると、枠を入れ替えます
      • 枠のバー: 音のボタン (この枠の音を出す) / 🎚 音の左右と音量 / 💬 チャット欄 / ≋ 弾幕 / 📌 ピックアップ / 🔖 あとで見る / 📃 再生リストに入れる / ⏱ 同期のずれ (アーカイブのとき) / ⟳ 読み込み直し / ⛶ その枠だけ全画面 / ✕ 閉じる
      • 🎚 では、その枠の音を左・真ん中・右から聞こえるようにしたり、音量 (0〜200%) を変えたりできます。「⇆ 2 枠を左右に分ける」で、音の出ている 2 枠を画面の位置どおり左右に分けます
      • 「⛶」(Shift + F) で、分割したまま全画面にします。上端にマウスを寄せるとバーが出ます
      • 「ℹ️」(I) で、各枠の種類 (ライブ・アーカイブ・動画)・配信の時間・今の視聴者数・再生数・アーカイブ同期できるかを一覧で見られます

      「自動再生」(L) を ON にすると、配信中のチャンネルを全部並べます。その後も 1 分ごとに、始まった配信の枠を足し、終わった配信の枠を消します。

      • ON にするとき、自分で入れた枠が置き換わるなら、先に確かめます
      • ON の間に ✕ で閉じた配信は、入れ直しません (OFF → ON で戻ります)。自分で入れた枠は消しません

      設定 → 自動再生

      • 自動再生の対象: すべてのチャンネルか、ピックアップ (📌) だけか
      • メンバーになっていないメンバー限定配信は再生しない: ログイン中のアカウントで見られるかを、枠に入れる前に確かめます
      • 自動再生の最大枠数: 配信中のものが多くても、この数までしか再生しません。回線が細いときや、パソコンが重いときは減らしてください
      • ピックアップ (📌) の配信をメイン枠に優先して置く: ピックアップのライブ配信を大きいメイン枠に入れ、ほかはサブ枠に回します。最大枠数に届いたときも、ピックアップを先に入れます。メイン枠の無い均等レイアウトと、クルーズ中は並べ替えません
      • 配信予定の枠を用意する: 開始前から枠を作り、最初から見られるようにします。配信中のものが 1 つも無いときは、次に始まる配信予定と、その開始から 1 時間以内に始まる予定を出します
      • 配信中が無いときは、最近の配信を流す: 深夜などライブが 1 本も無いときに、チャンネルの最近終わった配信を 4 枠流します (ピックアップが先、一度見たものは除く)。ライブが始まったら片付けます

      「クルーズ」(C) を ON にすると、一定の間隔でメイン枠と音声を次の配信へ回し、いろいろな配信を少しずつ見られます。自動再生を使わず、自分で並べた枠でも使えます。

      • 間隔は 設定 → 自動再生 →「クルーズの間隔」で変えます
      • 均等レイアウトでは並びはそのままで、音声だけ次の枠へ移ります。空き枠は回さず、レイアウトも変えません
      • 自動再生で枠を組み替えるときは、「メイン + サブ」のレイアウトを優先します
      • 「📺 チャンネル」(F) で、追加したチャンネルの配信中・配信予定と、それ以外を一覧します。配信中・予定の行を押すと、空いている枠に入ります
      • 行の「最近 ⌄」でそのチャンネルの最近の配信を開き、📌 でピックアップに入れます
      • ピックアップ: 今注目しているチャンネル (箱企画の参加者など)。上の「📺 すべて / 📌 ピックアップ」で一覧を絞れて、自動再生や通知の対象にもできます
      • 下の欄に @チャンネル名・チャンネルの URL・動画の URL を入れると追加できます
      • 🔔 通知: チャンネルの配信が始まると知らせます。対象は 設定 → 自動再生 →「通知の対象」で選びます

      設定 → チャンネル (チャンネルパック)

      • チャンネルパックは、チャンネルの一覧をまとめたものです。ホロライブ (同梱版) は最初から入っています。パックごとに、まとめて外したり戻したりできます。自分で追加したチャンネルと、ピックアップに入れたチャンネルは外しません
      • パックを探す: Hakomado のリポジトリ (GitHub) に集めたパックの一覧から選べます。利用者が作って投稿した非公式のもので、各事務所・配信者とは関係ありません。誤りや追加の希望は GitHub で知らせてください
      • チャンネルパックを読み込む: ほかの人が作ったパックの URL か中身を貼るか、ファイルを選んで足します。登録済みのチャンネルはそのままです
      • チャンネルパックを書き出す: 同梱のホロライブ・読み込んだパック・自分で追加したチャンネル・すべてから選んでパック (JSON) にし、ほかの人に配ったり公開したりできます
      • 「📚 ライブラリ」(B): 🎞 最近の配信 (最近 7 日に終わった配信) / 🕘 視聴履歴 (100 件) / 🔖 あとで見る (100 件) / 📃 再生リスト
      • あとで見る: 枠のバーや一覧の 🔖 で入れます。「▶ 今の枠で順に再生」で今ある枠に順に入れ、最後まで見た枠には次が入ります。最後まで見たものは消えます
      • 再生リスト: 名前を付けた並び (30 個・1 つに 200 本まで)。「＋ 新規」「▦ 今の枠から作る」「📥 読み込む」で作り、URL の欄や、枠のバー・一覧の 📃 で足します。⠿ で並べ替え、行の名前は枠に出す名前になります
      • 「▶ 順に再生」は今の枠に上から入れて、見終わった枠に次を入れます (最後まで見たものに ✓ を付け、次は続きから)。「⏱ まとめて同期再生」は全部を一度に並べて、アーカイブを同じ瞬間にそろえます (16 本まで)
      • 上のバーの「⏱ アーカイブ同期」を押すと、配信の時間帯が重なるアーカイブを、配信していた実際の時刻でそろえて再生します。アーカイブが 2 本そろっていないときは薄く出ていて、押すと使えない理由 (ライブ配信中・ふつうの動画など) が出ます
      • ほかの枠は「基準」の枠 (始めたときに音を出している枠) に合わせます。上のバーや枠の ⏱ で選び直せます
      • 声や画面の出来事で合わない分は、枠の ⏱ でずれを足し引きします。ずれは動画ごとに覚え、再生リストや共有するコードにも入ります
      • 上のバーのつまみで、同期している全部のアーカイブを同じ時刻に動かせます

      「🔗 共有」で、今の枠か再生リストを選んで、4 つの形式にできます。

      • 画像: X などに添えて投稿します。QR を読むと YouTube で開け、Hakomado では同じ並びで開けます。画像に付ける説明 (ALT) の文もコピーできます。「𝕏 に投稿」で、画像・名前・リンクを入れた X の投稿画面を開きます (投稿ボタンは自分で押します。初めてのときは x.com へのアクセスの許可を聞きます)
      • コード: #Hakomado … の 1 行 (16 本まで)。X での文字数も出します
      • テキスト: 1 行に 1 本。名前・同期・レイアウト・ずれ・枠の名前まで全部入ります。AI チャットに渡して直してもらうこともできます
      • 取り込み用リンク: Hakomado が無い人も YouTube の再生リストとして見られます (50 本まで)

      受け取ったものは「📥 読み込む」に貼ります (画像はドロップでも。入力欄の外で Ctrl + V しても開きます)。読み取った内容を確かめて、「▦ 枠に並べる」か「📃 再生リストとして保存」を選びます。取り込み用リンクを開いたときもここに来ます。

      • 弾幕: 各枠のライブチャットを画面に流します。枠の ≋ で枠ごとに ON / OFF (決めていなければメイン枠だけ)。D で全部を一時的に消せます。文字の大きさ・速さ・行数などは 設定 → 弾幕
      • チャット欄: 枠の 💬 で開きます。幅・文字の大きさ・アイコンを隠すかは 設定 → チャット欄 (開いているチャット欄にすぐ反映)
      • 枠の線: 音が出ている枠と、ライブ配信中の枠に付ける線の見た目 (両方のときは音の線が優先)。設定 → 枠の線
      • 設定・チャンネル (ピックアップを含む)・視聴履歴・あとで見る・再生リスト・表示言語を、1 つのファイルに書き出します
      • 拡張機能を削除して入れ直したり、別の版 (開発用のフォルダ・ID を固定する前の版) に切り替えたりすると、保存した内容は引き継がれません。その前に書き出しておき、あとで読み込んで戻してください
      • 読み込むと、今の設定・チャンネル・視聴履歴・あとで見るは、ファイルの内容に置き換わります。いま枠に入っている配信はそのままです
      1〜9その枠だけ音を出す

      ?この画面を開く

      この拡張機能で発生したエラーと、動作しなかった機能の記録です。不具合の報告に使用します。

      • 記録はこのパソコン内にのみ保存され、外部には送信されません。新しい順に最大 100 件を保存し、7 日を過ぎたものは削除します。同じ内容は 1 件にまとめ、発生回数を表示します
      • GitHub で報告: 記録と環境情報 (バージョン・ブラウザ・OS) を記入した Issue の作成画面を開きます。送信前に内容を確認・編集できます。Issue は公開されるため、公開したくない情報 (動画 ID・チャンネル名など) は削除してから送信してください。GitHub のアカウントが必要です
      • コピー: 同じ内容をクリップボードにコピーします。メールなど GitHub 以外で報告する場合に使用してください

        🔗 共有

        「短縮リンクを作る」を押すと、このセット (動画・レイアウト・同期のずれ・名前) を Hakomado のサイトに送り、短いリンクを作ります。リンクを知っている人だけが見られます (サイトの一覧には載りません)

        📥 読み込む

        共有された画像 (Ctrl+V で貼るか、ドロップ)・コード (#Hakomado …)・テキスト・取り込み用リンク、YouTube の URL (1 行に 1 つ) や再生リストの URL を貼れます。投稿の文をまるごと貼っても読めます

        🤖 AI チャットに作ってもらう

        見たいものを書いて頼み文 (見たいもの・書き方の説明・登録しているチャンネルの一覧) をコピーし、Claude などの AI チャット (Web 検索が使えるもの) に貼って送ります。返ってきたリストを上に貼るか、取り込み用リンクを開くと読み込めます
