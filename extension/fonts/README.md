# fonts

拡張機能に同梱しているフォント (視聴セットの共有画像のタイトルを、どの PC でも同じ見た目で描くため)。
外部から読み込むことはせず、ここにあるファイルだけを使う (`grid.js` の `loadShareTitleFont`)。

| ファイル | フォント | 版 | ライセンス |
| --- | --- | --- | --- |
| `MPLUSRounded1c-ExtraBold.ttf` | [M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c) ExtraBold (Copyright 2016 The Rounded M+ Project Authors) | 1.060 ([google/fonts](https://github.com/google/fonts/tree/main/ofl/mplusrounded1c) の `MPLUSRounded1c-ExtraBold.ttf`) | SIL Open Font License 1.1 (`OFL.txt`) |

更新するときは、google/fonts から同じファイルを取り直して置き換える。
