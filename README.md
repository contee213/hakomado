# Hakomado

[English](README.en.md) | 日本語

YouTube の配信を 1 画面で最大 16 枠並べて同時視聴する Chrome / Edge 拡張機能です。
各枠にライブチャットを弾幕として流したり、チャット欄を横に出して書き込んだりできます。
ブラウザでログインしている YouTube アカウントがそのまま使われるので、メンバー限定配信も見られます。

個人が作った非公式のツールです。使う前に [免責事項](#免責事項) を読んでください。

## 主な機能

- **分割表示**: 均等・メイン + サブ・PinP (メインの中に小窓)・縦長 (どの枠も 9:16。ショート・縦型の配信向け) のレイアウト。どの枠も 16:9 に自動で合わせます (ショートの枠は 9:16 に寄せます)
- **弾幕 / チャット欄**: 各枠のライブチャットを弾幕で流したり、横に出して書き込んだり
- **チャンネル**: 追加したチャンネルの配信中 / 予定と、最近終わった配信を一覧表示 (初期データとして、いくつかのチャンネルが入っています。⚙ 設定からまとめて外す / 戻すこともできます)
- **自動再生**: 配信中のチャンネルを自動で並べ、始まった / 終わった配信に合わせて枠を増減
- **まとめて選ぶ / 🤝 コラボ**: チャンネル (配信中・配信予定) やライブラリ (最近の動画・視聴履歴・あとで見る) の ☐ で、同じ画面の中の配信を何本でも選び、「▦ まとめて枠に入れる」で空いている枠に一度に入れます (足りなければ 16 枠まで足します)。開始の時刻が近く、タイトルで相手の名前や同じハッシュタグに触れている配信には「🤝 N」が付き、押すとコラボの相手ごとまとめて選べます
- **🎲 おまかせ**: 空き枠のボタンで、まだ出ていない配信を 1 本選んで入れる (ピックアップのライブ → ほかのライブ → 最近の動画の順)。自動再生は、ライブが無いときに最近の動画を流すこともできる
- **ピックアップ**: 今注目しているチャンネル (箱企画の参加者など) だけを自動再生・通知の対象にできる
- **通知 / 視聴履歴 / あとで見る**: 配信開始の通知、見た配信の視聴履歴、あとで見たい配信 (🔖。今の枠で順に再生でき、最後まで見ると消える)
- **📃 再生リスト**: 名前を付けた配信の並び (30 個まで。名前は 40 文字まで。最初は空の「新規マイリスト」が 1 つあります) を、ライブラリの「📃 再生リスト」で縦一列に並べて編集できます (「＋ 新規」「▦ 今の枠から作る」、URL の追加欄、「ℹ️ 枠の情報」や一覧の 📃 で入れる、⠿ のドラッグで並べ替え、枠に出す名前の書き換え)。再生のしかたは 2 通り: 「▶ 順に再生」は今の枠に上から入れて見終わった枠に次を入れ、「⏱ まとめて同期再生」は全部を一度に並べてアーカイブを同じ瞬間にそろえます (枠の数と同じ 16 本まで)。同期再生の再生リストはレイアウト・基準の動画・動画ごとのずれも保存し、再生中に ⏱ で直したずれも書き戻します。「🔗 共有」で人に渡せます (下の「🔗 共有 / 📥 読み込む」)。行にはタイトル・チャンネル名 (追加した直後に取得) と、配信中・配信予定・見られない (削除・非公開・メンバー限定) の印が出ます。「▶ 順に再生」は最後まで見た動画に ✓ を付けて次は続きから再生し、行の「▶ ここから」でその行から再生できます。同期再生は見ていた位置を保存して、次は続きから同期します。⧉ で複製、✕ で外したものは「元に戻す」で戻せます。YouTube の再生リストの URL を貼ると中身をまとめて追加できます。人からもらったものは「📥 読み込む」へ。そこで見たいものを書くと、Claude などの AI チャットに作ってもらう頼み文もコピーできます
- **🔗 共有 / 📥 読み込む**: 同じ画面の 2 つの側 (上の切り替えで行き来でき、上部バーの 🔗・📥 はそれぞれの側で開く)。今の枠 (視聴セット) か再生リストを選んで、渡す相手に合わせた 3 つの形式にできます。**画像** (サムネイルをレイアウトの形で画像いっぱいに並べ、名前と QR を重ねたもの。QR の中身は下のリンクと同じで、スマホのカメラで読むと YouTube で開ける。作者名と、各枠のチャンネル名・タイトルも描ける。X に添える ALT の文もコピーできる。「𝕏 に投稿」で画像・名前・リンクを入れた X の投稿画面を開ける (投稿は自分で押す。初回は x.com へのアクセスの許可を聞く))・**リンク** (`https://www.youtube.com/watch_videos?video_ids=ID,ID,…&hkl=<レイアウト>&hks=<ずれ>&title=名前&hakomado=1`。16 本まで。名前を付けなかったときは `title=` が YouTube に出す仮の名前で `hakomado=0` (読んでも名前にしない)。DM などで直接送る。Hakomado が入っていれば開くだけで同じ並びになり、入っていない人には YouTube の一時的な再生リストとして開く)・**テキスト** (1 行に 1 本。名前・同期・レイアウト・ずれ・枠の名前まで全部入る。17 本以上もこれで)。「📮 サイトに投稿」で、このセットを入れた Hakomado のサイトの投稿画面を開く (X でログインして自分で投稿する)。受け取ったものは「📥 読み込む」に貼る (画像はドロップでも。画面のどこかで Ctrl+V しても開きます) と内容を読み取り、「▦ 枠に並べる」か「📃 再生リストとして保存」を選べます。コード (`#Hakomado …`) や、以前の取り込み用リンクも読めます。リンクを開いたときもここに来ます
- **音の左右・音量・遅延**: 枠のバーの 🎚 で、その枠の音を左 / 真ん中 / 右から聞こえるようにしたり、音量 (0〜200%) を変えたりできます (「ℹ️ 枠の情報」の各行の L / C / R でも変えられます)。「⇆ 2 枠を左右に分ける」で、音の出ている 2 枠を画面の位置に合わせて左右に振り分けます (コラボの 2 視点の聞き分けに。ヘッドホン向け)。ライブ配信では「音の遅延」で、その枠の音だけを遅らせられます (映像はそのまま)。コラボで、ほかの枠より声が先に聞こえるときに使います
- **⏱ アーカイブ同期**: コラボ配信の各視点のアーカイブを、配信していた実際の時刻でそろえて再生します。使えないとき (ライブ配信中・ふつうの動画など) はボタンが薄くなり、押すと理由が出ます
- **ℹ️ 枠の情報**: 各枠の種類 (ライブ・配信前・アーカイブ・動画)・チャンネルとタイトル・配信の時間や公開日・今の視聴者数・再生数・再生位置・アーカイブ同期できるかを一覧で見られます (<kbd>I</kbd>)。各行で音の左右 (L / C / R)・📌 ピックアップ・🔖 あとで見る・📃 再生リスト・チャンネル登録・👍 高評価ができ、タイトルを押すと YouTube で開きます
- **右クリックで追加**: YouTube の動画・配信へのリンクや視聴ページを右クリック →「Hakomado の空き枠に追加」で、開いているマルチビュー画面の空き枠に入れる (空き枠が無ければ枠を 1 つ足す。画面が開いていなければ新しいタブで開く)
- **日本語 / 英語**: ブラウザの言語に合わせて表示 (設定で固定も可)

## 動作環境

- Google Chrome / Microsoft Edge 128 以降 (Manifest V3)

## インストール

### Chrome ウェブストアから (おすすめ)

[Chrome ウェブストアの Hakomado](https://chromewebstore.google.com/detail/bhmbchggpdficakjfllkmfkpbdpddomp) を開いて「Chrome に追加」を押します。
限定公開なので、ストアの検索には出ません (このリンクから開いてください)。新しい版はブラウザが自動で入れます。

### ZIP から (開発者モード)

GitHub のリリースには、ストアより先に新しい版が出ます (ストアは審査のあとで同じ版を追いかけます)。

1. [リリースのページ](https://github.com/contee213/hakomado/releases/latest) から `hakomado-x.y.z.zip` をダウンロードして展開
2. Chrome で `chrome://extensions` (Edge なら `edge://extensions`) を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダ (`manifest.json` が入っているフォルダ) を選ぶ
5. ツールバーの Hakomado アイコン (パズルのピースからピン留め) をクリックするとマルチビュー画面が開く

新しい版にするときは、新しい ZIP を同じフォルダに上書きで展開し、拡張機能ページの「⟳」を押してから、マルチビュー画面を再読み込みしてください。
リリースの ZIP は拡張機能の ID を `lhafnnpnfpgogdbapeepkgohemnnifpp` に固定しているので、別のフォルダに展開し直しても同じ拡張機能のままで、
設定やチャンネルは引き継がれます。

ストア版と ZIP 版は ID の違う別の拡張機能です。乗り換えるときは、⚙ 設定 →「バックアップ」で書き出して新しいほうで読み込み、古いほうを削除してください。

> **v0.2.0 以前から入れ替えるとき**: v0.2.0 までの ZIP は ID を固定していなかったので、ID を固定した版に入れ替えるときだけ、
> 一度別の拡張機能として扱われます。入れ替える前に ⚙ 設定 →「バックアップ」→「ファイルに書き出す」で書き出し、
> 新しい版で「ファイルから読み込む」で戻してください。戻せたら、古い版は拡張機能ページから削除してかまいません

## クイックスタート

1. ツールバーの Hakomado アイコンでマルチビュー画面を開く
2. 上部の「自動再生」を押すと、配信中のチャンネルが自動で並びます
3. 自分で選ぶときは、空いている枠に URL / 動画 ID / `@チャンネル名` を貼るか、今の配信は「📺 チャンネルから選ぶ」、終わった配信は「📚 ライブラリから選ぶ」で選びます
4. 音を出す枠は、枠のバーの 🎧 か数字キー (`1`〜`9`) で切り替え
5. 並べ方は上部の「▦ レイアウト」から

細かい操作とキーは、画面右上の「📖」(使い方。`?` キーでも開く) で確認できます。インストール後に初めて開いたときに出る使い方ツアーも、ここからもう一度見られます。設定は「⚙」からです。
不具合が発生した場合は、「📖」(使い方) の「不具合の報告」でエラーの記録を確認し、「GitHub で報告」または「コピー」から報告してください (記録はパソコン内にのみ保存され、自動では送信されません)。

> [!TIP]
> - 見たいチャンネルが無いときは、上部の「📺 チャンネル」の画面の「⚙ 管理」から追加できます
> - 特定のチャンネルだけを並べたいときは、そのチャンネルを 📌 でピックアップに入れ、⚙ 設定の「自動再生の対象」を「ピックアップ (📌) だけ」にします
> - 16 枠より多く見たいときは、別のウィンドウでもう 1 つ開けます (自動再生は、別のタブで表示中の配信を飛ばします)

## チャンネルパック

Hakomado の初期データはホロライブのチャンネルだけです。ほかのグループのチャンネルは、誰かが作った「チャンネルパック」を読み込んで足せます (「📺 チャンネル」の「⚙ 管理」、または ⚙ 設定 →「チャンネル」タブから開く「チャンネルの管理」)。パックは URL・中身の貼り付け・ファイルのどれでも読み込めます。読み込むと今のチャンネル一覧に足され (登録済みのチャンネルはそのまま)、パックごとにまとめて外せます。同梱のホロライブ・読み込んだパック・自分で追加したチャンネルを、それぞれパックとして書き出すこともできます。

「パックを探す」では、このリポジトリの [`packs/`](packs/) に集めたパックの一覧から 1 クリックで読み込めます (一覧のパックは利用者が投稿した非公式のものです)。パックの投稿・更新は PR で受け付けています。手順は [`packs/README.md`](packs/README.md) を見てください。

パックは次の形の JSON ファイルです。`packs/` に投稿するほか、GitHub (raw) や Gist などに置いて、その URL を配ることもできます。

```json
{
  "app": "hakomado",
  "type": "channels",
  "name": "パックの名前 (読み込んだパックの一覧に出る。50 文字まで)",
  "author": "作った人 (任意)",
  "updated": "2026-11-21",
  "channels": [
    {
      "channelId": "UCxxxxxxxxxxxxxxxxxxxxxx",
      "name": "チャンネル一覧に出す名前",
      "handle": "@xxxx",
      "group": "グループ名 (省略するとパックの名前)",
      "icon": "https://yt3.googleusercontent.com/... (任意)"
    }
  ]
}
```

- 必須は `app`・`type`・`channels` と、各チャンネルの `channelId` (`UC` で始まる 24 文字) です
- 1 つのパックに入れられるのは 1,000 チャンネル、ファイルは 2MB まで
- `icon` は YouTube の画像 (`yt3.ggpht.com`・`yt3.googleusercontent.com`・`i.ytimg.com`) だけ使います。無いときは、チャンネル一覧を開いたときに少しずつ取りに行きます
- 中身はデータとして読むだけで、知らない項目や形の違う値は取り込みません

## 権限とプライバシー

| 権限 | 使い道 |
|---|---|
| `storage` | 設定・枠の内容・チャンネルをブラウザ内に保存 |
| `declarativeNetRequestWithHostAccess` | 下記のヘッダー書き換え |
| `https://www.youtube.com/*` | 視聴ページ・ライブチャットを枠に表示、チャンネル情報・配信状況の取得 |
| `https://schedule.hololive.tv/*` | 初期データのチャンネルの配信予定の取得 (アドオン「ホロジュール」。設定 → アドオンで OFF にできる) |
| `https://www.nijisanji.jp/*` (任意) | にじさんじのライブスケジュールの取得 (アドオン「にじさんじ」。初期値は OFF で、設定 → アドオンで ON にしたときだけ許可を求める) |
| `https://www.vspo-schedule.com/*` (任意) | ぶいすぽっ!の配信スケジュールの取得 (アドオン「ぶいすぽっ!」。有志の非公式サイト。初期値は OFF で、設定 → アドオンで ON にしたときだけ許可を求める) |
| `https://schedule-share-json.s3.ap-northeast-1.amazonaws.com/*` (任意) | STPR (すとぷり など) の公式の配信予定の取得 (アドオン「STPR (すとぷり)」。schedule.stpr.com が使っているデータの置き場所。初期値は OFF で、設定 → アドオンで ON にしたときだけ許可を求める) |
| `contextMenus` | 右クリックのメニュー「Hakomado の空き枠に追加」 |

- 通信先は YouTube と配信予定サイトのほか、新しい版の確認 (`api.github.com`)、「パックを探す」を押したときのパックの一覧 (`raw.githubusercontent.com`)、自分で指定したパックの URL だけです。データを外部のサーバーに送ることはありません。詳しくは [プライバシーポリシー](docs/privacy.md) を見てください
- YouTube へのリクエストにはブラウザの Cookie (ログイン状態) が使われます。メンバー限定配信を表示するため、また自動再生でメンバー限定配信を見られるか確認するためです
- YouTube の視聴ページ・ライブチャットは `X-Frame-Options` ヘッダーで他のページへの埋め込みを禁止しているため、
  **マルチビュー画面のタブだけ**を対象にこのヘッダーを外すルール (declarativeNetRequest のセッションルール) を登録しています。
  それ以外のヘッダーはそのままで、タブを閉じたり別のページに移ったりするとルールも外れます
- 枠に入れた YouTube のページの中で動くスクリプトや CSS は、URL に `hakomado=1` が付いた、マルチビュー画面の枠の中でだけ働きます。
  普段 YouTube を見るときには影響しません

## 制限事項

- 枠の数が多いほど重くなります。PC の性能に応じて枠数を調整してください (自動再生の最大枠数は設定で変えられます)
- 初期データのチャンネルで、配信予定サイトに載らない突発の配信は「配信中」にならないことがあります
- アーカイブ (配信終了後) は、YouTube のチャットのリプレイを弾幕・チャット欄に出します。チャットのリプレイが無い配信 (チャットを切っていた配信など) では出ません
- 初期データのチャンネルは作成時点 (2026 年 11 月) の情報です

## 開発メモ

- `extension/` が拡張機能の本体です。主なファイル: `grid.*` (マルチビュー画面)、`favorites.js` (チャンネルと配信状況)、
  `layouts.js` (レイアウト)、`content/` (枠に入れた YouTube のページで動くスクリプト)
- メイン + サブのレイアウトとおすすめは `tools/layout-picks.json` に並べてあり、`tools/gen-layouts.js` で `extension/layouts-generated.js` に書き出しています。
  一覧を変えたら `node tools/gen-layouts.js` で作り直してください (共有コードに入る key は変えない)
- バージョン: `manifest.json` の `version` がリリースバージョンです (`chrome://extensions` やストアに出るのはこれだけ)。
  ビルド番号 (コミットの通し番号) と日付は `extension/build.js` に入り、使い方 (📖) と設定 (⚙) の画面の下に「0.2.0 · build 120 (2026-11-22)」のように出ます。
  `build.js` は、`extension/` のファイルを変えたコミットのときだけフック (`.githooks/pre-commit` → `tools/stamp-version.js`) が書き込みます
  (`web/` や README だけのコミットでは上がりません)。マージで `build.js` が衝突したら、どちらを取っても構いません
  クローンしたら一度だけ `git config core.hooksPath .githooks` を実行してください (Node.js が必要です)
- リリース: `manifest.json` の `version` を上げてコミットし、同じ番号のタグ (例: `v0.2.0`) をプッシュすると、
  GitHub Actions (`.github/workflows/release.yml`) が `extension` の中身を ZIP にしてリリースを作ります。タグと `version` が違うと止まります
- 開発中は、リポジトリを `git clone` して `extension` フォルダを読み込むと、変更をすぐ試せます
- 拡張機能の ID: リリースの ZIP にだけ、`release.yml` が `manifest.json` の `"key"` (公開鍵 `tools/release-key.pub`) を差し込み、ID を固定します
  (`node tools/release-key.js id` で表示)。リポジトリの `extension/` には入れないので、開発用のフォルダはフォルダの場所で決まる別の ID になり、
  同じ Chrome のプロファイルに開発版と配布版を並べて入れられます (保存したデータも別々)。対になる秘密鍵はリポジトリに入れていません
  (CRX を作るときだけ要ります)。ストア版は別の ID (`bhmbchggpdficakjfllkmfkpbdpddomp`) で、ZIP 版とは揃えません (`CHROMEWEBSTORE.md`)
- テスト: `npm test` (Node.js 22 以上。依存パッケージは無いので `npm install` は要りません)。`tests/` にあり、push と PR のたびに
  GitHub Actions (`.github/workflows/test.yml`) でも回ります。リリースの ZIP もテストが通ってから作ります。
  E2E テスト: `npm ci` と `npx playwright install chromium` のあと `npm run test:e2e`。`e2e/` にあり、`extension/` を読み込んだ
  Chromium をまっさらなプロファイルで起動して、マルチビュー画面と service worker を動かして確かめます (外への通信は止めるので、
  YouTube やアカウントには触れません)。これも push と PR のたびに回ります。同梱の Chromium が動かない環境では
  `E2E_CHANNEL=msedge` で Edge を使えます (市販版の Chrome は拡張機能の読み込みの指定を無視するので使えません)。
  実際の YouTube を使う確認は `tests/MANUAL.md` の手順で手で行います
- 埋め込みプレイヤー (`youtube.com/embed`) は拡張機能のページからだと再生を拒否される (エラー 152) ため、通常の視聴ページを枠に入れています
