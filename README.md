# hukumado

[English](README.en.md) | 日本語

YouTube の配信を 1 画面で最大 16 枠並べて同時視聴する Chrome / Edge 拡張機能です。
各枠にライブチャットを弾幕として流したり、チャット欄を横に出して書き込んだりできます。
ブラウザでログインしている YouTube アカウントがそのまま使われるので、メンバー限定配信も見られます。

> [!NOTE]
> 個人が作った非公式のツールです。YouTube / Google、カバー株式会社 (ホロライブ) とは関係ありません。
> YouTube やホロジュールのページの構成が変わると、一部の機能が動かなくなることがあります。
> YouTube の利用規約を確認のうえ、自己責任で使ってください。

## 主な機能

- **分割表示**: 均等 (1×1〜4×4 のうち画面を広く使える 9 種) と、大きいメイン枠 + 小さいサブ枠の組み合わせ (1+5、2+8、3+9 など 12 種) から選択
  - どの枠もちょうど 16:9 になるよう自動で大きさを調整 (黒帯なし)。「画面いっぱい」表示も可
  - 枠はドラッグで入れ替え (再読み込みなし)。1 枠だけ全画面表示も可
- **弾幕**: 各枠のライブチャットを右から左へ流す。絵文字・メンバースタンプ・スーパーチャットにも対応
- **チャット欄**: 枠の横に表示して書き込み可能。文字サイズ・幅を調整可
- **音声**: 基本は 1 枠だけ音を出す (どの枠かは枠の外側の線と上部バーで表示)。枠内のプレイヤーで複数枠を同時に聞くことも可
- **お気に入り**: ホロライブ所属 (在籍中) のタレント 67 チャンネルと公式系 8 チャンネルを最初から登録済み。配信中 / 予定を一覧表示
- **自動再生**: お気に入りで配信中のチャンネルを全部再生し、配信が始まったら枠を足し、終わったら枠を消す。メンバーになっていないメンバー限定配信は除外 (設定で切り替え)
- **クルーズ**: 一定時間ごとにメイン枠と音声を次の配信へ回し、いろいろな配信を少しずつ見る
- **日本語 / 英語**: ブラウザの言語に合わせて表示 (日本語以外は英語)。設定画面で固定も可

## 動作環境

- Google Chrome / Microsoft Edge 111 以降 (Manifest V3)

## インストール

ストアには公開していないので、開発者モードで読み込みます。

1. このリポジトリをダウンロード (Code → Download ZIP を展開、または `git clone`)
2. Chrome で `chrome://extensions` (Edge なら `edge://extensions`) を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ `extension` フォルダを選ぶ
5. ツールバーの hukumado アイコン (パズルのピースからピン留め) をクリックするとマルチビュー画面が開く

更新したときは、拡張機能ページの「⟳」を押してから、マルチビュー画面を再読み込みしてください。

## 使い方

### 画面

上部バーは、左によく使うもの、右にたまに使うものを置いています。

| ボタン | 動作 |
|---|---|
| ▶ 自動再生 | 配信中のお気に入りを全部再生し続ける (下記)。ON のときは青く表示 |
| ⟳ クルーズ | 一定時間ごとにメイン枠と音声を次の配信へ回す (下記)。ON の間はボタンが左から青く満ちていき、満ちたら次へ回る |
| ★ お気に入り | お気に入りの一覧と配信状況 |
| 🔊 番号 名前 | 今音が出ている枠。押すとミュート ⇄ 直前の状態に戻す |
| ▦ レイアウト名 | レイアウトと表示方法を選ぶ |
| ≋ 弾幕 | 全枠の弾幕の表示 (ON のときは青く表示) |
| ⛶ | 分割したまま全画面 (上部バーは隠れ、画面の上端にマウスを寄せると出る。Esc で戻る) |
| ⚙ / ? | 設定 / 使い方とキー操作 |

ウィンドウが狭いときは、文字を省いてアイコンだけになります (ボタンに乗せると説明が出ます)。
F11 (ブラウザの全画面) のときも上部バーは隠れ、上端にマウスを寄せると出ます。
分割したままの全画面中に枠の ⛶ で 1 枠を全画面にし、Esc で戻すと分割したままの全画面に戻ります。

### 枠

- 空の枠に URL / 動画 ID / `@チャンネル名` を貼って「読み込む」(チャンネルの場合は今配信中の枠を開きます)。
  「★ お気に入りから選ぶ」でお気に入りから選ぶこともできます
- 枠にカーソルを乗せると操作バーが出ます。左にその枠の番号と名前、右によく使う操作が並びます

| ボタン | 動作 |
|---|---|
| ⠿ | ドラッグして別の枠と入れ替え |
| 🔇 / 🔊 | その枠だけ音を出す (他はミュート) |
| 💬 | チャット欄を枠の右に表示 (書き込みもここから) |
| ≋ | この枠の弾幕の表示 |
| ★ | この枠のチャンネルをお気に入りに登録 |
| ⟳ | 再読み込み (映像やチャットの調子が悪いとき) |
| ⛶ | この枠を全画面で見る (その枠の音を出し、Esc で戻すと元の音声に戻る) |
| ✕ | 枠を閉じる |

💬 と ≋ は ON のとき青く表示します。小さい枠では名前を省き、ボタンを 2 段に折り返して全部押せるようにしています。

### レイアウト

- 上部の「▦ レイアウト」から選択。枠の番号はメイン → サブの順で、レイアウトを変えても 1 番の配信は 1 番の場所に移ります
- 右上で表示方法を選べます
  - **16:9 に合わせる** (既定): 枠の中に黒帯が出ません。画面とレイアウトの比率が違う分は外側の余白になります。
    一覧の % は今の画面で映像が占める割合 (90% 以上は緑)
  - **画面いっぱい**: 余白なしで画面を埋め、映像は枠に合わせて拡大 (はみ出た端は切れる)

### お気に入り

- 上部の「★ お気に入り」(`F`) で一覧を開きます。「● 配信中」「予定」が上、それ以外はその下にまとめて表示
  - 項目をクリックすると読み込み (空の枠から開いた場合はその枠、上部から開いた場合は空いている枠)
  - 上の欄で名前・@チャンネル名を絞り込み、下の欄で `@チャンネル名` / チャンネル URL / 動画 URL を追加
  - 「● 配信中」の見出しの「空いている枠に入れる」で、まだ表示していない配信中のチャンネルを空いている枠に入れます
- 既定のチャンネルは ✕ で外せます (勝手には戻りません。「外したホロライブのチャンネルを戻す」で戻せます)
- 配信状況は 1 分間キャッシュします。「⟳ 更新」で取り直し

### 自動再生

上部の「▶ 自動再生」(`L`) を ON にすると、お気に入りで配信中のチャンネルを全部 (最大 16) 再生し続けます。

- ON にしたとき: 配信中のものを全部、件数に合ったレイアウトで再生します (枠がちょうど埋まるものを優先。例: 5 件→2+3、7 件→3+4、12 件→3+9)。
  表示中の配信は読み込み直さずに 1 番 (メイン) 側に残し、配信中でない枠は空にします
- ON の間: 1 分ごとに確認し、配信が始まったら枠を後ろ (サブ側) に足し、終わったら枠を消してレイアウトを組み替えます
  - 一時的な取りこぼしで消さないよう、2 回続けて見つからなかったときに消します。取得に失敗した回は消しません
  - ON の間に自分で URL を入れた枠は消しません
- ON の間に ✕ で閉じた配信は入れ直しません。OFF → ON で入れ直します
- OFF にすると今の枠はそのままで、増減だけ止まります
- メンバーになっていないメンバー限定配信は入れません (⚙ 設定 →「自動再生」で切り替え。既定は ON)。
  枠に入れる前に、ログイン中のアカウントで見られるかを視聴ページで確認します。確認できなかった配信は一度入れて、
  枠のプレイヤーが「メンバー限定で見られない」と分かった時点で外します。自分で読み込んだ枠は外しません

### クルーズ

上部の「⟳ クルーズ」(`C`) を ON にすると、一定時間 (既定 2 分。⚙ 設定 →「自動再生」で 30 秒〜10 分) ごとに、
表示中の配信の並びを 1 つずつ回します。

- 「メイン + サブ」のレイアウトでは、サブの先頭がメイン枠に移り、メイン枠だった配信は最後尾のサブ枠へ。音声はメイン枠 (1 番) に付いていきます
- 均等レイアウトでは並びはそのままで、音声だけ次の枠へ移ります
- 自動再生と一緒に使うと、件数に合った「メイン + サブ」のレイアウトを優先して選びます
- 配信は読み込み直しません (枠の位置を入れ替えるだけ)。全部ミュート中は音を出さずに並びだけ回します
- 自分で音声を切り替えたり枠を入れ替えたりすると、そこから数え直します。1 枠だけ全画面で見ている間は回しません

### 音声

- 音の出ている枠は、枠の外側の線と上部バーの「🔊 番号 チャンネル名」で分かります
- 拡張機能側の操作 (枠の 🔊 / 数字キー / 全画面) はその枠だけ音を出し、他はミュートします
- 枠内の YouTube プレイヤーのスピーカーはその枠だけを切り替えます (他の枠はそのまま。複数枠を同時に聞きたいとき用)
- 上部バーのボタン (`M`) でミュート ⇄ 直前の状態に戻す
- ここでのミュート操作は、普段の YouTube の音量設定には保存されません

### 設定 (⚙)

- **弾幕**: 流れる時間・文字サイズ・不透明度・流れる場所・同時表示数・投稿者名・スーパーチャットの強調
  - 流れる場所は「上 / 中央 / 下」と高さ (枠の何 % を使うか) で決めます。設定画面の見本に加えて、動かしている間は実際の各枠にも範囲の帯が出ます
- **音声の枠**: 音が出ている枠の線の色 (水色 / ピンク / オレンジ / グリーン / パープル / ホワイト の 6 色)・太さ・光・アニメーション。
  上部バーの音声表示は線の色と関係なく、他の ON のボタンと同じ青です
- **チャット欄**: 文字サイズ・幅・投稿者アイコンの表示
- **自動再生**: メンバー限定配信を除外するか・クルーズの間隔
- **表示言語** (設定画面の右上): 自動 (ブラウザの言語) / 日本語 / English。変えると画面を読み込み直します (見ている枠はそのまま戻ります)

設定と各枠の内容はブラウザ内に保存されます (下の「開き直したとき・複数ウィンドウ」を参照)。

### 開き直したとき・複数ウィンドウ

- 枠・レイアウト・表示方法・自動再生・クルーズは、タブ (ウィンドウ) ごとの「視聴セッション」として保存されます。
  弾幕などの設定 (⚙) とお気に入りは全タブ共通で、どこかで変えると他のタブにもすぐ反映されます
- 開いたときに、他のタブで使っていない前回のセッションがあれば選べます
  - **前回の続きから** (セッションが複数あれば、それぞれ「この内容で再開」) / **新しく始める** / **自動再生で始める**
  - 各セッションには日時・レイアウト・件数と、配信の名前 (5 件まで。それ以上は「ほか N 件」) が出ます
  - 同じタブを再読み込みしたときは、確認なしで続きから再開します
- 複数のディスプレイで見るときは、ウィンドウを分けてそれぞれで hukumado を開けば、別々の配信を並べられます。
  ツールバーのアイコンは押すたびに新しいタブを開きます (同じウィンドウに複数開いても、それぞれ別の視聴セッションになります)
- 自動再生はタブごとに動きます。2 つのウィンドウの両方で ON にすると、同じ配信が両方に入ります
- 保存しておくセッションは最新 8 つまでです (空のものと古いものから消えます)

### キーボード

| キー | 動作 |
|---|---|
| `1`〜`9` | その枠だけ音を出す |
| `Shift` + `1`〜`9` | その枠を全画面 |
| `Shift` + `F` | 分割したまま全画面 |
| `M` | ミュート ⇄ 直前の状態に戻す |
| `D` | 弾幕の全体切り替え |
| `F` | お気に入りを開く |
| `L` | 自動再生の ON / OFF |
| `C` | クルーズの ON / OFF |
| `?` | 使い方とキー操作を開く |

## 権限とプライバシー

| 権限 | 使い道 |
|---|---|
| `storage` | 設定・枠の内容・お気に入りをブラウザ内に保存 |
| `declarativeNetRequestWithHostAccess` | 下記のヘッダー書き換え |
| `https://www.youtube.com/*` | 視聴ページ・ライブチャットを枠に表示、チャンネル情報・配信状況の取得 |
| `https://schedule.hololive.tv/*` | ホロライブの配信予定 (ホロジュール) の取得 |

- 通信先は YouTube とホロジュールだけです。データを外部のサーバーに送ることはありません
- YouTube へのリクエストにはブラウザの Cookie (ログイン状態) が使われます。メンバー限定配信を表示するため、また自動再生でメンバー限定配信を見られるか確認するためです
- YouTube の視聴ページ・ライブチャットは `X-Frame-Options` ヘッダーで他のページへの埋め込みを禁止しているため、
  **マルチビュー画面のタブだけ**を対象にこのヘッダーを外すルール (declarativeNetRequest のセッションルール) を登録しています。
  それ以外のヘッダー (Content-Security-Policy など) はそのままで、タブを閉じるとルールも外れます
- 枠に入れた YouTube のページの中では、プレイヤー以外を隠す CSS と、ミュート操作・チャットの読み取りを行うスクリプトが動きます。
  これらは URL に `hukumado=1` が付いた、マルチビュー画面の枠の中でだけ働きます

## しくみ

```
extension/
├── manifest.json
├── background.js        マルチビュー画面を開く。画面のタブだけに X-Frame-Options を外すルールを登録
├── i18n.js              表示言語 (日本語 / 英語) の切り替えと文言
├── _locales/            拡張機能の名前・説明 (ja / en。それ以外の言語は en)
├── grid.html / .css / .js   マルチビュー画面 (枠・レイアウト・音声・お気に入り画面・自動再生・クルーズ・設定・視聴セッションの保存と選択)
├── layouts.js           レイアウトの定義と、全枠が 16:9 になる列幅・行高の計算
├── danmaku.js           弾幕の描画 (重ならない行に割り当てて流す)
├── favorites.js         お気に入りの保存と配信状況の取得 (ホロジュール / YouTube)
├── presets.js           既定のお気に入り (ホロライブ。英語表示用の名前も)
├── icons/               アイコン (icon.svg が元。PNG は 16 / 32 / 48 / 128px に書き出したもの)
└── content/
    ├── watch.js / watch.css   枠の視聴ページをプレイヤーだけの表示にし、親画面と連絡
    ├── watch-main.js          YouTube プレイヤーの API でミュートを切り替え、見られる動画か (メンバー限定など) を知らせる (ページ側で実行)
    └── chat.js                枠のライブチャットから新着コメントを読み取って親画面へ送る
data/
└── hololive-channels.json   既定のお気に入りを作るときに調べたチャンネル一覧 (卒業生なども含む)
```

- 埋め込みプレイヤー (`youtube.com/embed`) は拡張機能のページからだと再生を拒否される (エラー 152) ため、通常の視聴ページを枠に入れています
- ホロライブのチャンネルの配信状況は [ホロジュール](https://schedule.hololive.tv/lives) を 1 回取得してまとめて判定し、
  各配信のチャンネルは YouTube の oEmbed で調べています。それ以外のチャンネルは YouTube の `/live` ページを個別に確認します

## 制限事項

- 枠の数が多いほど重くなります。PC の性能に応じて枠数を調整してください
- ホロジュールに載らない突発の配信は、お気に入りや自動再生で「配信中」にならないことがあります
- アーカイブ (配信終了後) のチャットリプレイは弾幕に対応していません
- 既定のお気に入り (`presets.js`) は作成時点 (2026 年 11 月) の公式サイトの情報です
