# 似ているのに違うところ (UI の不揃い)

拡張機能のマルチビュー画面 (`grid.html` とダイアログ) で、同じか似た役割なのに、操作・遷移・見た目・色・大きさ・文言が違うところの一覧。2026-11-25 に `main` (fbfd6c1) のコードから洗い出した。画面の項目は [screen-items/](screen-items/README.md)、流れは [screen-flow.md](screen-flow.md) を見る。

- 直したら「状態」を「済 (#PR 番号)」にする。直さないと決めたものは「そのまま」にして、理由を書く
- 行番号は洗い出したときのもの。ずれていたら関数名で探す
- 「方向」は案。B・C の多くは、どちらにそろえるかを決めてから直す

## 理由があるので外したもの

- 設定と枠の情報だけ背景の暗さが .15 (ほかは .5)。後ろの枠を見ながら調整するため (grid.css:1091-1092)。枠の情報にはコメントが無いので、書き足すとよい
- 通知の画面だけ右上に出る。🔔 のそばに出すため (grid.css:868)
- 同期の調整パネルの ✕ に「(Esc)」が無い。パネルはダイアログではなく、Esc で閉じないため
- ツアー中のチャンネル・ライブラリは `show()` で開くので Esc で閉じない (grid.js:7685 のコメント)
- 共有の名前・作者名は Enter で何も起きない。主ボタンが 1 つに決まらないため
- 再生リストの行を押しても読み込まない。名前の欄を編集に使うため
- 並べ替えのドラッグが再生リストにしか無い。ただし、あとで見るも入れた順に再生するので、機能の欠けとも言える
- 登録チャンネルの画面は普通のチェックボックスと「すべて選ぶ」、ライブラリは ☐ と Ctrl/Shift で選ぶ。画面の役割が違うため
