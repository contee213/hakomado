# チャンネル・ライブラリ

同じダイアログ `#favorites` を 2 つの入り口で使い分ける。`openFavorites(target, view)` の view が `'channels'` なら「📺 チャンネル」、`'library'` なら「📚 ライブラリ」。見出し・タブ・出す項目は `setFavMode` で切り替える (`favMode` = `all` / `archive` / `history` / `saved` / `playlists`)。

## 📺 チャンネル (`#favorites`)

上部バーの「📺 チャンネル」(`#openChannels`)・F キー・空き枠の「📺 チャンネルから選ぶ」・枠のメニューから開く。登録チャンネルの配信中・配信予定を見て枠に入れ、ピックアップ (📌) を付け外しする画面。チャンネルを足す・外すのは「⚙ チャンネルの管理」で行う (この画面には ✕ と追加の欄を置かない。docs/channel-manage.md)。✕・Esc・背景のクリックで閉じる。枠から開いたときは、その枠が読み込み先になる (`favTarget`)。
