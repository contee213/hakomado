# マルチビュー画面 — 上部バーと同期

マルチビュー画面 (`extension/grid.html`) のうち、枠 (tileTemplate) 以外の部分。上部バー・同期の時刻バーと調整パネル・速度メニュー・自動再生の進み具合・全体のお知らせ・枠の並び (#grid) を扱う。

キー操作は `document` の keydown で受ける (`setupToolbar`)。入力欄・select・textarea・ダイアログの中にフォーカスがあるときと、Ctrl / Alt / ⌘ を押しているときは効かない。

## 上部バー (`header.toolbar`)

マルチビュー画面の一番上に常に出る高さ 36px のバー。左に見え方と再生の操作、右に各ダイアログを開くボタンを並べる。閉じることはなく、全画面のときだけ隠れる (上端にマウスを寄せると出る)。

## 同期の調整パネル (`#syncDock`)

アーカイブ同期を ON にすると出る (上部バーの ⏱ で ON にしたとき・☰ を押したとき。✕ で閉じたあとは、再開などで自動で始まったときは出さない)。グループごとに基準・補正・✨ 自動補正などを調整する。枠の上に浮かぶ半透明の小窓か、画面の右の列 (枠の並びはその分縮む) で出す。✕ か ☰ でしまい、同期をやめると隠れる。見出し以外の中身 (`#syncDockBody`) は grid.js の `Sync` の `Dock` が作る。

## 枠の並び (`#grid`)
