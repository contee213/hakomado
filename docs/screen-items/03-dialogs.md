# ダイアログ

## 起動画面 (`#startDialog`)

拡張機能のページを開いたとき (再開できる前回の内容があるとき) と、上部バーのロゴ「Hakomado」(`#brandHome`) を押したときに出る。どの内容で視聴するかを選ぶ。
起動時は必ずどれかを選ぶ (✕ なし・Esc でも閉じない)。ロゴから開いたときは ✕ と Esc で何もせず閉じる。

- 背景を押しても閉じない (`closeOnBackdrop` を付けていない)

## 読み込む (`#xferDialog` 読み込むの側)
