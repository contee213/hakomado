# 設定・使い方

## 設定 › 共通 (`#settings`)

上部バーの「⚙ 設定」(`#openSettings`) で開くモーダル。上に 8 つのタブ、下にバージョンと「すべて初期値に戻す」を置く。✕・Esc・背景 (枠の外) のクリックで閉じる。
