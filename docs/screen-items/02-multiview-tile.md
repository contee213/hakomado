# マルチビュー画面 — 枠

## 空き枠の入力 (`.tile.is-empty .empty`)

中身の無い枠 (`.tile.is-empty`) に出る入力欄。URL・動画 ID・@チャンネル名を入れるか、一覧・おまかせから選んで枠に入れる。入れると `.is-empty` が外れて消える。
空き枠のバーには ⠿・番号・✕ だけが出る (「動画の入った枠」の節の状態 A)。

## 動画の入った枠 (`.tile`)

マルチビュー画面の 1 枠ぶん。`grid.html` の `<template id="tileTemplate">` から `buildTiles` が 16 枠ぶん作り、`renderTile` が中身に合わせて切り替える。
枠の上に操作バー (`.bar`) を重ね、マウスを乗せたとき (フォーカスがあるとき) だけ出す。Twitch の枠は映像の上にバーの場所を取り (ふだんは黒一色)、中身は同じくマウスを乗せたときだけ出す。URL の枠はバーを出さず、操作は「ℹ 枠の情報」から。

## 枠の状況 — 音・全画面・同期・ドラッグ (`.tile`)

## 音の左右・音量・遅延のパネル (`.mix-panel`)

枠のバーの 🎚 で開く、枠の中の小さなパネル。もう一度 🎚 を押すと閉じる。枠を空にすると閉じる。音の左右は「ℹ 枠の情報」でも変えられる。
値は枠の中の YouTube ページ (content/watch.js の Web Audio) に送る。

## 枠の中の YouTube ページ (content/watch.js・content/watch.css)
