# 画面項目表・画面項目状態表

拡張機能 (`extension/`) の画面 (`grid.html` とそこから開くダイアログ) にある項目と、状態ごとの出方をまとめた表。画面の流れは [../screen-flow.md](../screen-flow.md) を、保存するものと出し入れは [../data-io.md](../data-io.md) を、似ているのに操作や見た目が違うところは [../ui-consistency.md](../ui-consistency.md) を、決めたことは [../decisions.md](../decisions.md) を、確かめ方は [../check-procedure.md](../check-procedure.md) を見る。

画面の項目を足したり、出る条件を変えたりしたら、ここも直す。表は `grid.html`・`grid.js`・`tour.js` などのコードから起こしたもので、コードで確かめきれなかったところは備考に「未確認」と書いてある。

## 表の見方

### 画面項目表

| 列 | 中身 |
| --- | --- |
| No | 画面ごとの通し番号。状態表と同じ番号を使う |
| 項目名 | 画面に出る文言。アイコンだけの項目は title の文言で補う |
| 種類 | ボタン / トグル / タブ / 入力 (1 行) / 入力 (複数行) / チェック / スライダー / 選択 / ラジオ / 表示 / 一覧 / リンク / 領域。拡張機能の外の項目 (00-entry.md) はメニュー / ショートカットも使う |
| 要素 | `#id`、id が無ければ `.class` や `[data-…]`。JS で作るものは「(JS)」を付ける |
| 内容・動作 | 押したとき・変えたときに起きること、行き先の画面 |
| 値・初期値 | 文字数の上限、スライダーの範囲・刻み・単位、初期値、保存先のキー |
| キー | キーボードの操作 |
| 備考 | 補足。探すときの手がかりとして関数名を書くことがある |

### 画面項目状態表

画面ごとに、意味のある状態 (A・B・C…) を表の上に書き、項目がその状態でどう出るかを記号で示す。状態で変わらない項目は省くことがある。

| 記号 | 意味 |
| --- | --- |
| ○ | 表示・操作できる |
| ● | 表示・選択中 / ON |
| △ | 表示しているが操作できない |
| − | 出ない |
