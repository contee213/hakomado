# 共有・読み込みの整理 (A案) 設計メモ

## ねらい

- 「何を共有するか (今の枠 / 再生リスト)」と「どの形式か」を分けて、どちらからでも同じ形式を作れるようにする
- 読み込みの入口を 1 つにまとめ、何を貼っても読み取り、読み取った後に「枠に並べる」か「再生リストとして保存」かを選ぶ
- 古い版が作ったコード・テキスト・リンク・画像はすべてそのまま読める。新しい版が作るものも古い版で読める

## 用語

| 言葉 | 意味 |
|---|---|
| 視聴セット | 今の枠に並んでいる配信 (レイアウト・同期のずれを含む)。保存はしない |
| 再生リスト | 名前を付けて保存した並び |
| 形式 | 画像・コード・テキスト・リンクの 4 つ (「視聴セットのコード」は「コード」と呼ぶ) |

## 入口

| 場所 | いま | これから |
|---|---|---|
| ツールバー | 🔗 (共有と貼り付けが同じ画面) | **🔗 共有** と **📥 読み込む** の 2 つに分ける |
| ライブラリ › 再生リスト › 🔗 | 再生リスト用の共有画面 | 共有画面を「その再生リスト」を選んだ状態で開く |
| ライブラリ › 📥 貼り付けて作る | 再生リスト用の貼り付け画面 | 「📥 読み込む」に名前を変え、読み込み画面を開く (保存を主ボタンに) |
| 取り込み用リンクを開いたとき | 貼り付け画面 (保存) | 読み込み画面 |
| 空き枠の入力欄 | URL 1 本 | そのまま (コードを貼ったら読み込み画面に回すのは任意) |

ツールバーの 🔗 / ライブラリの 🔗 以外では 🔗 を使わない (「リンクをコピー」は 📋 にする)。

## 🔗 共有画面

```
┌ 🔗 共有 ────────────────────────────── ✕ ┐
│ 共有するもの [ 今の枠 (4 本)          ▾ ]     │  ← 今の枠 / 再生リスト (名前順)
│ 名前         [ 夜の 4 窓               ]     │
│ [画像] [コード] [テキスト] [リンク]           │  ← タブ (切り替えても左上を動かさない)
│ ─────────────────────────────────────── │
│  (タブの中身: 画像のプレビュー / 1 行のコード / │
│   テキスト欄 / リンク)                        │
│  入るもの: … / 入らないもの: …                │
│  [📋 コピー] [⬇ 保存 (画像のみ)]  状態表示     │
└─────────────────────────────────────┘
```

### 形式ごとの中身

| 形式 | 本数 | 入るもの | 入らないもの | 向いている用途 |
|---|---|---|---|---|
| 画像 | 先頭 16 本 | レイアウト・ずれ・名前 (画像に描く + QR) | 枠の名前 | X などに添付。見て分かる |
| コード | 先頭 16 本 | レイアウト・ずれ・名前 | 枠の名前 | X などの本文に貼る |
| テキスト | 200 本 | 全部 (名前・同期再生・レイアウト・ずれ・枠の名前) | — | 中身を全部渡す・AI に直してもらう |
| リンク | 先頭 50 本 | 名前 | ずれ・レイアウト・同期 | Hakomado が無い人も YouTube で見られる |

- 今の枠から: テキスト・リンクも作れるようにする (同期中ならずれ・基準も入れる。枠の名前も入れる)
- 再生リストから: 画像も作れるようにする (先頭 16 本。レイアウトは再生リストのもの、無ければ本数に合わせる)
- 名前の初期値: 今の枠 = このタブで最後に付けた名前 (空なら既定の名前)、再生リスト = その名前
- 今の枠に配信が無いとき・空の再生リストは「共有するものがありません」と出し、タブの中身は空にする
- 共有画面の「📃 再生リストとして保存」は外す (ライブラリの「▦ 今の枠から作る」に 1 本化)

## 📥 読み込み画面

```
┌ 📥 読み込む ──────────────────────────── ✕ ┐
│ [ 画像・コード・テキスト・リンク・URL を貼る / │
│   画像をドロップ                           ]  │
│ ─ 読み取った内容 ─                             │
│ 「夜の 4 窓」 4 本 / 2x2 / 同期 (ずれあり)     │
│ 読めなかった行: 1                              │
│ 名前 [ 夜の 4 窓 ]                             │
│ [▦ 枠に並べる] [📃 再生リストとして保存]       │
│ ▸ 🤖 AI チャットに作ってもらう                  │
└─────────────────────────────────────┘
```

- 貼った (ドロップした) 時点で読み取り、内容を確認表示する。テキストは打ち終わりを待って読む
- 画像は QR を読む。読めなければ「画像に QR が見つかりません」
- **▦ 枠に並べる**: 今の枠を置き換える。17 本以上なら先頭 16 本で、その旨を出す。自動再生は OFF
- **📃 再生リストとして保存**: 名前欄の名前で保存。同じ名前があれば「置き換えます」と確認表示に出す。保存したらライブラリで開く
- 主ボタン (Enter で押されるもの): ツールバーから = 枠に並べる / ライブラリから = 保存 / 取り込み用リンクから = 保存
- AI チャットへの頼み文は、この画面の折りたたみに移す

## 中のつくり

- 共有するものを 1 つの形にそろえる: `{ name, items: [{videoId, label, offset}], sync, layoutId, ref }`
  - 今の枠 → この形に変換する関数、再生リスト → ほぼそのまま
  - 各形式 (コード・テキスト・リンク・画像) はこの形から作る。`renderShareImage` も今の枠ではなくこの形から描く
- 読み取りを 1 つにする: `parseViewingSet` と `parsePlaylistText` をまとめ、上と同じ形 + `{bad, tooMany}` を返す (最大 200 本)。枠に並べるときに先頭 16 本にする
- ダイアログ: `shareDialog` を共有画面に、`plDialog` を読み込み画面に作り替え、`plShareDialog` はなくす
- 文言: `share.*` / `plShare.*` / `plDlg.*` を整理し直す (日本語・英語)
- 権限・外部への通信は変わらない見込み (変わったら CHROMEWEBSTORE.md も直す)

## 決めたこと (2026-11-21)

1. ツールバー: **🔗 共有** と **📥 読み込む** の 2 つのボタンに分ける
2. 読み込んだ後: **確認表示を挟んで選ぶ**。取り込み用リンクを開いたときの主ボタンは **再生リストとして保存**
3. 名前: **コードにも入れる**

### コードに名前を入れる形

```
#Hakomado 2x2.<動画 ID ×n>~0,1.5,*0,-2 "夜の 4 窓"
```

- コードの直後に半角スペース 1 つと `"名前"` を付ける (名前が空なら付けない)
- 名前の中の `"` と改行は除く。長さは再生リストの名前と同じ 40 文字まで
- 古い版: 正規表現がコードの直後で終わる (次の文字が英数字・`_`・`-` でなければよい) ので、名前は無視されて今までどおり読める
- 新しい版: `SHARE_CODE_RE` の後ろに `(?:\s"([^"\r\n]{1,40})")?` を足して名前を読む。名前の無いコードもこれまでどおり読める
- 画像の QR にも同じもの (名前付きのコード) を入れる
- 共有画面の「入るもの」の表は、コード・画像とも「名前」を入るものに移す
