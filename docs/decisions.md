# 決めたことの記録

Hakomado の作者 (使う人) が決めたことと、その理由の一覧。同じ話を蒸し返さないため、また後から理由を確かめるために残す。

- 新しく決めたら、ここに足す。決め直したら、古い行は消さずに「→ 決め直し (日付)」と書き、新しい行を足す。
- 画面の見た目・動き・言葉の決まりは [design-guide.md](design-guide.md) に、その元になった判断は [ui-consistency.md](ui-consistency.md) にある。ここには、それ以外のことを書く。
- 「見直す条件」は、その条件になったら決め直してよい、という意味。条件が無いものは、言われるまで提案し直さない。
