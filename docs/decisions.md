# 決めたことの記録

Hakomado の作者 (使う人) が決めたことと、その理由の一覧。同じ話を蒸し返さないため、また後から理由を確かめるために残す。

- 新しく決めたら、ここに足す。決め直したら、古い行は消さずに「→ 決め直し (日付)」と書き、新しい行を足す。
- 画面の見た目・動き・言葉の決まりは [design-guide.md](design-guide.md) に、その元になった判断は [ui-consistency.md](ui-consistency.md) にある。ここには、それ以外のことを書く。
- 「見直す条件」は、その条件になったら決め直してよい、という意味。条件が無いものは、言われるまで提案し直さない。

## Twitch

機能ごとの対応の一覧は [platform-support.md](platform-support.md)。

| 日付 | 決めたこと | 理由 | 見直す条件 |
| --- | --- | --- | --- |
| 2026-11-25 | Twitch はできるだけ YouTube と同じだけ対応する。チャンネル登録 → 共有・履歴 → プレイヤーの操作 → 弾幕 の順に進める | 使う人が Twitch も同じように並べて見たい | − |
| 2026-11-25 | Twitch のチャンネルの配信中・最近の VOD は、チャンネルの公開ページの先頭の構造化データから読む (Cookie なし・ログインなし) | 公式の API はログインかアプリの鍵が要る。非公式の内部の窓口は使わない | ページの作りが変わって読めなくなったとき |
| 2026-11-25 | 共有コードに Twitch の枠を入れるときは、YouTube の分を今の形のまま残し、最後に `~t <枠の番号>=<名前>` を足す | 古い版でも YouTube の分は読める | − |
| 2026-11-25 | 視聴履歴には Twitch のライブも入れる。あとで見る・再生リストは VOD だけ | ライブはチャンネルごとに同じ ID で、開くたびに中身が変わる | − |
| 2026-11-25 | Hakomado Feed (`web/`) も、Twitch 入りのセットの投稿・表示まで対応する | 共有したセットが Feed で崩れないように | − |
| 2026-11-25 | Twitch の速度・音の左右・遅延・✨ 自動補正のため、公式の埋め込みプレイヤーの中に拡張機能のスクリプトを入れる (twitch.tv の許可がある間だけ、Hakomado の枠の中だけ) | 公式の埋め込みの命令に無い操作を、YouTube と同じように使うため | − |
| 2026-11-25 | Twitch の弾幕のコメントは、公式の埋め込みチャット欄にスクリプトを入れて読む。IRC への匿名の接続は使わない | 新しい通信先が増えず、匿名の接続は公式の文書から外されたやり方のため | チャット欄の作りが変わって読めなくなったとき |
