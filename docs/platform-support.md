# YouTube と Twitch の対応機能の比較

Hakomado の機能が、YouTube と Twitch のそれぞれでどこまで使えるかの一覧 (2026-11-25 時点。PR #104〜#108 のあと)。
Twitch の機能を足した・Twitch の都合で変えたときは、この表も直す。

- Twitch の枠の ID: チャンネルのライブは `tw:<ログイン名>`、VOD (過去の配信) は `tw:v:<番号>`
- Twitch の機能は、どれも twitch.tv の任意の権限を許可している間だけ使える (枠に Twitch の URL を初めて入れたとき・Twitch のチャンネルを登録するときに聞く)
- 印: ○ = 使える / △ = 一部だけ / × = 使えない / − = 当てはまらない。「未確認」は作ったが実際の画面で確かめていないもの

| 機能 | YouTube | Twitch ライブ | Twitch VOD | 備考 |

## Twitch の決まりで、できないこと・気を付けること

- **プレイヤーに何かが重なると止まる:** Twitch のプレイヤーは、上に何か (透明な要素・隣の枠の光や線も) が少しでも重なると、自動再生しない・再生の命令を受け付けない・再生中なら止まる。Hakomado は Twitch の枠を前に出し、重なって止まった枠は重なりが消えたら再生に戻す。重なっている間は枠に「上に重なっているものがあるので、Twitch が止まっています。外すと再生に戻ります」と出す
- **「特定のオーディエンス向けに指定されています」の VOD:** 見る人が確認画面で押すまで再生が始まらない。拡張機能からは飛ばさない
- **VOD のチャット:** 公式に読む方法が無いので、弾幕・チャット欄は無い
- **視聴者数・配信予定:** 公開ページに無い (公式の API とログインが要る)
- **ページの作り:** Twitch はときどきチャンネルの情報の無い共通のページを返す。1 回取り直し、読めなければ覚えない
