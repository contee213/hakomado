# データの入出力

拡張機能 (`extension/`) が、どこに何を保存し、どこから何を読み、どこへ何を出すかの一覧。2026-11-25 に `main` (b543728) のコードから起こした。

- 画面のどの操作で読み書きするかは、[screen-items/](screen-items/README.md) の各表の「値・初期値」欄にも書いてある。
- 権限と外への通信の理由は [../CHROMEWEBSTORE.md](../CHROMEWEBSTORE.md) の「権限と理由」「外への通信」にまとめてある。ここでは要点だけ書く。
- 保存するもの・通信する先を足す、消す、形を変えるときは、この文書も同じ PR で直す。

## 「取り戻せるか」の見方

消える操作の重さを決めるときに使う ([ui-consistency.md](ui-consistency.md) の決まり)。

- **作ったもの:** 使う人がこのアプリで作ったもの。消えると取り戻せない。消す操作には「元に戻す」か確認を付ける。
- **取り直せる:** YouTube などからもう一度取れるもの、使っていればまたたまるもの。
- **一時:** 消えても既定に戻るだけのもの、使う人が気にしなくてよいもの。

## 2. ほかの保存先

### chrome.storage.session (すべてのタブで共有、ブラウザを閉じると消える)

| キー | 中身 | 使うところ |
| --- | --- | --- |
| `gridTabs` | 開いているマルチビュー画面のタブ (最後に使った順) | 右クリックの追加の送り先 (`background.js`) |
| `statusShared` | 配信状況の取得結果 (アドオンの予定・チャンネルごとの状態・取得を控える間隔) | タブが複数あっても、YouTube などへの取得を 1 回で済ませる (`favorites.js`) |
| `videoStates` | 動画ごとの状態 (配信中・予定・終了、開始時刻、タイトル) | 同上 |
| `twvod:<番号>` | Twitch の VOD の配信の開始時刻 (VOD のページから。アーカイブ同期用) | 同上 |
| `twpage:<名前>` | Twitch のチャンネルのページから読んだもの (名前・アイコン・配信中か・最近の VOD) | 同上 (Twitch のチャンネル。読めなかったときは覚えない) |

### localStorage (この画面のブラウザだけ、消えても既定に戻るだけ)

すべて **一時**。バックアップには入らない (表示言語だけはバックアップの `lang` に入る)。

| キー | 中身 |
| --- | --- |
| `hakomado.lang` | 表示言語 (auto / ja / en)。バックアップに入る |
| `hakomado.settingsTab` | 設定で最後に開いたタブ |
| `hakomado.helpPage` | 使い方で最後に開いたページ |
| `hakomado.libTab` `hakomado.libScope` `hakomado.libKinds` `hakomado.libPlaylist` | ライブラリ・チャンネルの最後のタブ、すべて / ピックアップ、種類の絞り込み、開いていた再生リスト |
| `hakomado.shareTab` `hakomado.shareImgLabels` `hakomado.shareAuthor` | 受け渡しの最後のタブ、共有画像に枠の名前を入れるか、画像に描く作者名 |
| `hakomado.syncDock` | 同期の調整パネルの置き方と小窓の位置 |

## 3. ファイル・コード・リンクでの出し入れ

| 何を | 出す | 入れる | 中身 | 入れたときの動き |
| --- | --- | --- | --- | --- |
| バックアップ (`hakomado-backup-<日付>.json`) | 設定 › バックアップ「ファイルに書き出す」 | 「ファイルから読み込む」 | `settings`・`favorites` (📌 を含む)・同梱チャンネルの状態・`history`・`saved`・再生リスト・表示言語 | 件数を見せて確認してから、**今の内容をすべて置き換える** (足し合わせない)。知らない項目・形の違う値は捨てる |
| チャンネルパック (`hakomado-pack-<名前>.json`) | 設定 › チャンネル「⬇ 書き出す」(範囲を選ぶ) | 「読み込む」(ファイル・URL)、「パックを探す」 | チャンネルの一覧 | 確認してから、今の一覧に**足す** |
| 視聴セット (コード・取り込み用リンク・QR 付きの画像) | 📥 受け渡しの「共有」 | 📥「読み込む」、取り込み用リンク (`watch_videos?…&hakomado=`) | 枠の動画・レイアウト・枠の名前・同期のずれ・本編の位置・Twitch の枠 (コードの最後の `~t <枠の番号>=<名前>`・`v:<数字>`、リンクの `hkt=`。以前の版は無視して YouTube の分だけ読む) | 枠に並べる (今の枠を置き換える。Twitch の枠があれば twitch.tv の許可を聞く)。保存を選ぶと再生リストになる (Twitch のライブは入らない) |
| 再生リスト | 📚 再生リストの「🔗 共有」(画像・リンク・テキスト) | 📥 読み込む | 再生リストの動画 | 再生リストとして足す |
| スクリーンショット (PNG) | Alt+Shift+S | − | 枠の並び全体の画像 | ダウンロードとクリップボード。外へは送らない |
| エラーの記録 | 不具合の報告の「コピー」「GitHub で報告」 | − | エラーの記録と環境 (版・ブラウザ・OS) | GitHub の Issue 作成画面を開くだけ。送るかは使う人が決める |

## 4. 外との通信 (要点)

詳しくは [../CHROMEWEBSTORE.md](../CHROMEWEBSTORE.md) の「外への通信」。

- 開発者のサーバー (Hakomado Feed) とは通信しない。「📮 サイトに投稿」は Feed の投稿画面をタブで開くだけ。
- **読むだけ:**
  - YouTube: 配信状況・チャンネルのページ・oEmbed・フィード・登録チャンネル。登録チャンネルは、使う人が押したときと、アドオンが ON のときだけ読む。配信状況は画面を開いている間 1 分ごとに確かめ (通知が「知らせない」でも、配信中の件数のため)、チャンネルの新着 (RSS) を見に行くのは、ピックアップは 3 分・ほかは 15 分ごと (設定で変えられる。配信予定が出ている配信は開始の前後に動画のページで確かめる)。
  - Twitch のフォロー: 「Twitch のフォロー」の「フォローから選ぶ」を押してログインしたときだけ、公式の API (`api.twitch.tv`) で読む。アクセストークンは読み終えたら無効にし、保存しない。
  - Twitch: 登録した Twitch のチャンネルの公開ページ (先頭の構造化データだけ読んで打ち切る。1 チャンネル 2 分に 1 回まで)。twitch.tv の許可を外したときは、配信のサムネイル画像の転送先で配信中かだけを見る。
  - 配信予定のサイト: アドオンが ON のものだけ。
  - GitHub: 版の確認と、パックの一覧。
  - 使う人が入れた URL: パック、ドラッグした画像。
- **Cookie を付けるもの (`credentials: 'include'`、YouTube だけ):**
  - チャンネルの `/live` (`resolveLive`)
  - 動画・再生リストのページ
  - 登録チャンネル (`/feed/channels`)
  - ログインが要るアドオンの取得
  - ほかは `credentials: 'omit'`。
- **外へ出すもの:** 拡張機能から自動で送るものは無い。X・GitHub・Feed は、投稿画面を開くだけ。

## 5. 権限 (manifest.json)

理由は [../CHROMEWEBSTORE.md](../CHROMEWEBSTORE.md) の「権限と理由」。

- **permissions:** `storage`・`declarativeNetRequestWithHostAccess`・`contextMenus`・`scripting`・`activeTab`
- **optional_permissions:** `identity` (「Twitch のフォロー」の「フォローから選ぶ」を押したときだけ求める)
- **host_permissions:** `https://www.youtube.com/*`・`https://schedule.hololive.tv/*`
- **optional_host_permissions:** 使うアドオンや URL の枠を ON にしたときだけ求め、OFF にしたら手放す。
  - x.com
  - Twitch
  - にじさんじ・ぶいすぽっ!・STPR の予定
  - `https://*/*` (URL の枠)
