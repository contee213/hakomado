# チャンネルの管理を 📺 チャンネルの画面から分ける

📺 チャンネルの画面 (`#favorites`、`openFavorites(…, 'channels')`) から、チャンネルを足す・外す管理の操作を切り出し、「チャンネルの管理」の画面に分ける設計。[ui-consistency.md の A4](ui-consistency.md#a4-一覧の--で-1-件消す) の続き。2026-11-25 に `main` (69ac7a2) のコードから書いた。

**状態:** 決定 (2026-11-25)。実装は未

## なぜ分けるか

- 📺 チャンネルの画面は、主に「配信中のライブを探して枠に入れる」ために開く。チャンネルの管理はたまにしかしない。
- それなのに、探す画面に管理の操作が同居している。
  - 行の ✕ (`.fav-del`)。押すとすぐ消え、確認も「元に戻す」も無い。
  - 下の追加の欄 (`#favAdd`)。
- ✕ でチャンネルを消すと、📌 の印も黙って一緒に消える。どれに 📌 を付けていたか覚えていないと戻せない。
  - 📌 で絞った表示では ✕ を出していない。ただ「📺 すべて」の表示からは、📌 付きでも消せる。
- チャンネルは、パックや「登録チャンネルから選ぶ」でまとめて入ることがある。減らすときは 1 件ずつ ✕ を押すしかない。何十件も続けて消すので、1 件ごとの確認は嫌がられる。
- 管理の一部は、もう 設定 › チャンネル にある。管理が 2 か所に分かれている。

## 今の画面と操作 (コードで確かめたこと)

### 📺 チャンネルの画面 (`#favorites`)

| 操作 | 要素 | 動き |
| --- | --- | --- |
| 📺 すべて / 📌 ピックアップ | `#libScope` | 対象のチャンネルを絞る。ライブラリと共通 |
| 絞り込み | `#favFilter` | 名前・@ハンドル・グループで絞る |
| 行を押す | `.fav-item` | 配信中・予定の行は枠に入れる / ☐ で選んでまとめて枠に入れる |
| 最近 ⌄ | `.fav-arch` | そのチャンネルの最近の配信を行の下に開く |
| 📌 | `.fav-star` | `Favorites.setStar` でピックアップを付け外し |
| ✕ | `.fav-del` | `Favorites.remove`。確認なしで消す。📌 も消える。同梱 (ホロライブ) のチャンネルだけは `removedPresets` に残り、設定 › チャンネル の「戻す」で戻せる。自分で足したもの・パックのものは戻せない。📌 で絞っているときは出さない |
| 追加の欄 | `#favAdd` | `@ハンドル` / チャンネルの URL / 動画の URL で登録。📌 で絞っているときは 📌 も付ける。ライブラリのタブでは出さない |
| 空の案内 | `#favEmpty` | 「まだチャンネルがありません。下の欄に…」/ 📌 が無いときは使い方の案内 |

### 設定 › チャンネル (`#settings [data-panel="channels"]`)

| 操作 | 要素 | 動き |
| --- | --- | --- |
| パックの一覧 | `#packList` | 同梱・読み込んだパックごとに「外す」(確認あり、**📌 付きは残す**)。同梱は「戻す」もある |
| 登録チャンネルから選ぶ | `#subsOpen` → `#subsDialog` | YouTube の登録チャンネルを ☐ で選んで足す |
| パックを書き出す | `#packGroup`・`#packExport` | 範囲を選んで JSON に書き出す |
| パックを探す | `#catalogLoad` | 利用者が投稿したパックの一覧 |
| パックを読み込む | `#packIn`・`#packLoad`・`#packFile` | URL・中身・ファイルから足す |

### ほかにチャンネルが増える・📌 が変わるところ

- 枠のバー・ℹ️ 枠の情報の 📌 (`addTileToFavorites`): 📌 が無ければ、チャンネルを登録して 📌 も付ける。外すときは 📌 だけ外す (チャンネルは残る)。
- パックを外す (`removePack`)・同梱を全部外す (`removeAllPresets`) は、📌 付きを残す。**まとめて外すときに 📌 を守る形は、もうある。**

## 決めること 1: どの操作をどちらの画面に置くか

| 操作 | 案 | 良いところ | 気になるところ |
| --- | --- | --- | --- |
| **📌 ピックアップ** | **探す画面に残す** (管理の画面にも置く) | 付け外しが気軽にでき、探すときの絞り込みにもすぐ効く | 特に無し。管理の画面でも見えると、外す前に 📌 付きか分かる |
| **行の ✕** | 1-a. 探す画面から無くし、管理の画面だけに置く | 探す画面で消してしまう誤操作が無くなる。行が 1 つ短くなる | 探しながら「要らない」と気づいたとき、管理の画面に移って探し直す手間がかかる |
| | 1-b. 探す画面にも残し、消したあとに「元に戻す」を出す | 気づいたその場で消せる | 探す画面で消せることは変わらない。戻せるのは最後の 1 件だけ |
| | 1-c. 1-a に加え、管理の画面を開くとき、探す画面の絞り込みの文字を引き継ぐ | 1-a の手間が「開く 1 手 + ☐」で済む。探し直さなくてよい | 引き継いだ文字で絞られたまま開くので、全部を見たいときは消す必要がある |
| **追加の欄** | 2-a. 管理の画面に移す | 探す画面が探すことだけになる。管理の画面に、足す・外すがそろう | 探す画面で思い付いてすぐ足すことはできない (ただし枠の 📌 からは今どおり足せる) |
| | 2-b. 両方に置く | どちらからでも足せる | 探す画面が今と変わらない。同じ欄が 2 か所 |
| **☐ で選んでまとめて外す** | 管理の画面だけに置く | 自動でたくさん入ったチャンネルを一度に整理できる | 特に無し (探す画面の ☐ は「まとめて枠に入れる」用なので、混ぜない) |
| **パック (外す・戻す・書き出す・読み込む・探す)** | 3-a. 管理の画面に移し、設定 › チャンネル は「チャンネルの管理を開く」ボタンだけにする | チャンネルに関することが 1 か所にそろう | 設定にパックがあると覚えている人は、1 手増える |
| | 3-b. 設定 › チャンネル に残す | 今と変わらない | 管理が 2 か所に分かれたまま。パックの外し方を探すとき迷う |
| **登録チャンネルから選ぶ** | パックと同じ置き場所にする | 「まとめて足す」方法が同じ所に並ぶ | (パックの案と同じ) |

**おすすめ:** 📌 は探す画面に残す。✕ は **1-c** (管理だけ + 絞り込みを引き継ぐ)。追加の欄は **2-a**。パックと登録チャンネルは **3-a**。

**決定:** 📌 は探す画面に残す (管理の画面にも出す)。✕ は 1-c (管理の画面だけに置き、絞り込みの文字を引き継いで開く)。追加の欄は 2-a (管理の画面へ移す)。☐ でまとめて外すのは管理の画面だけ。パックと登録チャンネルから選ぶは 3-a (管理の画面へ移し、設定 › チャンネル は「チャンネルの管理を開く」ボタンだけ)。

## 決めること 2: 管理の画面の置き場所と入口

| 案 | 良いところ | 気になるところ |
| --- | --- | --- |
| A. 専用のダイアログ「⚙ チャンネルの管理」を作る | 一覧・☐・追加の欄・パックを、広く並べられる。📺 の見出しからも設定からも同じ画面が開くので、どこから来ても同じ | ダイアログが 1 つ増える。📺 から開いたとき、閉じたら 📺 に戻る必要がある (戻らないと探していた所を見失う) |
| B. 設定 › チャンネル のタブに一覧を足す | 入口が増えない。パックと同じ所にある | 設定のダイアログは 2 段組みで、何十件の一覧を入れると窮屈。📺 から開くと設定ごと開くので、閉じても 📺 に戻らない |
| C. 📺 チャンネルの画面の中で「管理」に切り替える (同じダイアログのまま、行に ☐ と ✕、下に追加の欄が出る) | 移る手間がいちばん少ない。絞り込み・スクロールの位置もそのまま | 今の「探す」と「管理」の区別が、切り替えの印だけになる。切り替えたまま忘れると、今と同じく消せる画面で探すことになる |

入口 (A のとき):

- 📺 チャンネルの見出しに「⚙ 管理」ボタン。開くと 📺 の上に重ね、閉じると 📺 に戻る。
- 設定 › チャンネル に「チャンネルの管理を開く」ボタン。
- 📺 の空の案内 (決めること 4)。
- キーは足さない (F は今どおり 📺 チャンネル)。

**おすすめ:** **A**。

**決定:** A (専用のダイアログ「⚙ チャンネルの管理」)。入口は上のとおり。📺 から開いたときは、閉じると 📺 に戻る。

## 決めること 3: まとめて外すときの確かめ方と 📌 の扱い

📌 はアプリで作ったもの (外れると戻す手がかりが無い) なので重く扱う。外したチャンネルのうち、同梱のものは「戻す」で戻せるが、自分で足したもの・パックのものは戻せない。

| 案 | 良いところ | 気になるところ |
| --- | --- | --- |
| A. 確かめる画面を 1 回出し、「📌 付きが N 件含まれます (📌 も消えます)」と書く | 何が消えるか分かってから外せる。まとめて 1 回なので、何十件でも 1 回で済む | 読み飛ばすと 📌 付きも消える |
| B. 確かめる画面を 1 回出す。📌 付きは既定で残し、「☐ 📌 付き (N 件) も外す」に印を付けたときだけ外す | パックを外すときと同じ動き。うっかり 📌 を失うことが無い | 📌 付きを外したいときは 1 手増える |
| C. 確かめずに外し、「N 件を外しました [元に戻す]」を出す (戻すと 📌 も戻る) | 止まらずに外せる | 知らせが消えたあとは戻せない。続けて別のものを外すと、前の分は戻せない |
| D. B のあとに C の「元に戻す」も出す | 確かめたあとで間違いに気づいても戻せる | 知らせが 1 つ増える |

管理の画面に 1 件ずつの ✕ を置くかも、ここで決める。

| 案 | 良いところ | 気になるところ |
| --- | --- | --- |
| a. 置かない (1 件でも ☐ → 外す) | 外し方が 1 つになり、どれも確かめる画面を通る | 1 件だけ外すときも 2 手 |
| b. 置き、押したら「元に戻す」を出す (📌 付きの行は ✕ を出さず、☐ でしか外せない) | 1 件なら 1 手。📌 付きは必ず確かめる画面を通る | 外し方が 2 つになる |

**おすすめ:** **D** と **b**。安全な側をとり、📌 は既定で守り、確かめたあとでも戻せるようにする。確かめる画面はまとめて 1 回なので、何十件消すときも止まるのは 1 回。

**決定:** B (確かめる画面を 1 回出し、📌 付きは既定で残す。「☐ 📌 付き (N 件) も外す」に印を付けたときだけ外す)。外したあとの「元に戻す」は出さない。1 件ずつの ✕ は、元に戻すが無いので a (置かない。1 件でも ☐ → 外す で、確かめる画面を通す)。

## 決めること 4: 空のときの案内

最初は同梱のチャンネルが入っているので、空になるのは「同梱を外した / 入れなかった」人。追加の欄を管理の画面に移すと、📺 の画面だけでは足し方が分からなくなる。

| 案 | 良いところ | 気になるところ |
| --- | --- | --- |
| A. 案内文に「⚙ チャンネルの管理を開く」ボタンを 1 つ置く | 足し方が全部ある画面に 1 手で行ける | 何をすればよいかは、移った先で探す |
| B. 空のときだけ、📺 の画面にも追加の欄を出す | 最初の 1 件をその場で足せる | 空かどうかで画面の形が変わる。足した瞬間に欄が消える |
| C. 主な足し方をボタンで並べる:「⚙ チャンネルの管理を開く」「📥 登録チャンネルから選ぶ」、同梱を外していれば「同梱のチャンネルを戻す」 | 何ができるか一目で分かる。よく使う足し方は 1 手 | 案内が少し長くなる |

- 📌 で絞って空のとき (`starEmpty`) は、📌 が探す画面に残るので今の案内のまま。
- 管理の画面が空のときは、同じ画面に追加の欄があるので「上の欄から足す」と案内する。

**おすすめ:** **C**。

**決定:** C (「⚙ チャンネルの管理を開く」「📥 登録チャンネルから選ぶ」、同梱を外していれば「同梱のチャンネルを戻す」をボタンで並べる)。
