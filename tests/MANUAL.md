# 手動確認の手順 (実際の YouTube を使うもの)

`npm test` は、YouTube に触らない部分 (チャンネルパック・視聴セットのコード・バックアップの検証・レイアウト・文言など) だけを試します。
`npm run test:e2e` (`e2e/`) は、マルチビュー画面のボタン・ダイアログ・ツアー・視聴セッションと、service worker のヘッダー書き換えの範囲を
本物のブラウザで試しますが、外への通信は止めているので、枠の中の YouTube は動きません。
YouTube のページの中で動く部分 (`content/`・枠の中のプレイヤー・ライブチャット) は、YouTube 側の変更で壊れやすく、
CI で動かすと不安定なので、大きく変えたときやリリースの前に、ここの手順で手で確かめます。

Chrome DevTools MCP (`.mcp.json` の `chrome-devtools`) を使うと、Claude Code から同じ手順を進められます。
ふだん使いのプロファイル (ログイン中の YouTube アカウント) につながるので、使う前に `CLAUDE.md` の注意を読んでください。

## 準備

1. Chrome で `chrome://inspect/#remote-debugging` を開き、「Allow remote debugging for this browser instance」をオンにする (DevTools MCP を使うとき。ブラウザを起動するたびに必要)
2. `chrome://extensions` で `extension/` を読み込む (読み込み済みなら再読み込み)
3. ツールバーのアイコンからマルチビュー画面を開く。service worker と画面のコンソールにエラーが出ていないこと

## 確かめること

| 何を | どうなればよいか |
| --- | --- |
| 枠に配信を入れる (URL・動画 ID・@チャンネル名) | 再生が始まり、枠の名前が出る |
| ライブチャット・弾幕 | 配信中の枠で、チャットが表示され、弾幕が流れる |
| 音の切り替え (クリック・ソロ・全部消音) | 選んだ枠だけ音が出る |
| 🎚 音の左右・音量 (ヘッドホンで) | L / R で片側から聞こえる。「⇆ 2 枠を左右に分ける」で 2 枠が左右に分かれる。そのあとも消音・ソロ・同期再生・広告のあとの音が今までどおり |
| アーカイブの同期再生 | 2 本以上で同期を ON にすると位置がそろい、一時停止・シークが全部に効く。画面の右に同期の調整パネルが出て、枠の並びがその分だけ横に縮む |
| 同期グループ | 時間の違うコラボ 2 組 (例: `k6fQMwzFPoM` / `hdHVlPKYKwQ` と `inmap2iySzA` / `XcNobZGLrB0`) を 2×2 に並べて同期すると「2 組 (4 本)」と出て、パネルにグループ 1・2、枠に色の線と番号が出る。グループごとの ⏸ はその組だけ止まる。行のグループを「同期しない」「グループ 3」(まだ無い番号は新しく作る)「自動」に変えると、組み直される (1 本だけ残った枠は「重なる枠がありません」)。上部バーのつまみは音を出している枠のグループを動かす |
| 同期の調整パネル | 行を選んで ← → で ±0.1 秒 (Shift 0.01)、↑ ↓ で行を移る (パネルの外では矢印キーは今までどおり音の枠を移す)。行の ↺ でその枠の補正が 0 (実際の時刻) に、見出しの ↺ でグループ全部が 0 に戻り。補正が 0 の行には ↺ が出ない。グループの図に、開始のあたりを拡大した各枠の横棒 (補正の分が水色で、補正前の位置に細い線。基準より前に始まった枠は基準の開始のところに出る。0.01 秒でも細く見える)・「基準 / 36秒前 / 2分後」・「✓ / ↻ あと 0.39秒」が出て、合うと ✓ になる。基準を先に始まった枠 (アキ) にして、後から始まった枠 (わため) を補正したときも、基準の行のわための開始の時刻に細い線が出て見比べられる。開始の差が 1 分より大きい枠が混ざると、間が詰まって棒に切れ目が入り、どの枠の開始も見分けられる。上には各枠の開始の時刻が重ならない分だけ (2 段で) 出る。▾ でグループをたたむと見出しと枠の数だけになり、↑ ↓ はたたんだ行を飛ばす。基準の行は頭のラジオボタンが 🔒 (🎬 本編のグループでは ◉) になり、押せない −0.1 / −0.01 / 0.00 / +0.01 / +0.1 / ⏸ だけで、← → でも動かない。図の基準の行は ✓。ほかの行の ±0.1 / ±0.01 は押し続けると続けて動き、放すと止まる (パネルの外で放しても止まる)。わため +3.40・アキ +3.10 のように基準にも補正が入っていると、同期を始めた・基準を変えたときに基準が 0、ほかが差の分 (アキ −0.30) になり、見え方は変わらない (🎬 本編のグループでは「▶ ここが 0:00」は出る)。⇲ / ⧉ で浮かぶ小窓と右の列を切り替えられ、小窓は見出しで動かせて、開き直しても同じ位置に出る。⇥ でたたむと番号と補正だけ。✕ で閉じると次に同期を始めても出ない (☰ か枠の ⏱ で出すと、また出るようになる)。枠の ⏱ でパネルが出て、その行が選ばれ、枠に点線が出る |
| ✨ 自動補正 (調整パネルのグループの見出し。今は音で合わせる) | コラボの 2 視点 (例: ガンギマリ姉妹 ラーメン屋 `k6fQMwzFPoM` 基準 / `hdHVlPKYKwQ`) で、話している場面から押す。測っている間 (最大 180 秒) 聞こえ方 (どの枠の音が出ているか) が変わらず、ボタンに進み具合が出る。結果は各行に「✨ −1.61」のように出て、「中間」がおよそ −1.60 秒 (声に合わせる値は −1.29 / −1.89 前後)。測っている間はほかのグループの ✨ 自動補正は押せない。反映すると ⏱ の補正が変わり、終わったあとも消音・ソロが今までどおり効く。止めて待っている枠・時間帯の外の枠が、測っている間に勝手に再生されない。35 秒を過ぎると、パネルの箱が「途中の結果」になり、各行に薄い「✨ −1.6x ○」、図に薄い ◆ と点線が出る (10 秒ごとに更新)。行の値は、枠ごとにここまでで一番よかった値 (黙っている区間で一時的に — になっても消えない)。90 秒を過ぎて、どの枠も ◎ で 2 回以上同じ値が出ると、箱が光って「どの枠も ◎ になりました。ここで決めますか？」と出る (勝手には終わらない)。◎ の値が 2 つに分かれて行き来する枠は ○ になる。「ここで決める」で終えられ、180 秒まで聞くと一番よかった値 (1 回の計算の値をまとめて採る) で終わる。5 人のコラボ (`1TEs3v4hA78,xm0ZxpDQYJg,yuLlvdYwtng,oXfefvzpPwo,vnOhAveMDB0`、おかゆ基準) では、補正 0 から測って、おおよそ ぺこら −0.28 / ミオ +8.14〜8.25 / ヴィヴィ −5.7〜−5.8 / AZKi −63.3 (1 分を超えるずれ。−32.8 は 30 秒ずれた偽の一致) になる。測っている間・計算中も、ほかの枠の再生や同期 (つまみ・↻) が止まらない。結果の箱の「測り直す」で今の位置から測り直せる。決められなかったときは黄色い箱に「測り直す」が出る。まだ補正していないグループでは ✨ のボタンが光る |
| 🎬 同時視聴 (調整パネルのグループの見出しで 🎬 同時視聴) | 時間のずれた同時視聴のアーカイブ 2 本で、パネルの各行の「🚩 開始位置」(または「⏲ 画面タイマー」+ Enter) を決めると、本編の同じ場面にそろい、つまみに「本編 h:mm:ss」が出る。ライブは「同期しない」から本編モードのグループに手で入れる。本編の位置を決めていない枠は動かず、そう表示される。ライブ 1 本 + アーカイブ 1 本ではライブが基準になり (シークバーは動かせない)、アーカイブがついてくる。🔗 共有のコードに「 ~!…」が付き、読み込むと本編モードで始まる。プレミア公開でない動画を行の 🎬 で本編にしてから共有すると、コードの最後に「,*番号」が付き、受け取った側でもその枠が 🎬 本編になる (🕒 コラボ配信で始まらない) |
| レイアウトの切り替え・枠の入れ替え (ドラッグ) | 枠が 16:9 のまま並び替わり、再生が止まらない |
| 自動再生 (L) | 配信中のチャンネルが枠に入り、終わった配信が外れる |
| 🔗 視聴セットのコード | コードを作ってほかのタブで貼ると同じ並びになる。QR の画像を貼っても読める |
| 取り込み用リンク (`watch_videos?…&hakomado=名前`) | 開くと取り込み画面に切り替わり、再生リストとして入る |
| 広告 | 広告が流れたあとも、音・同期が元どおり効く |
| 新しい版の確認 | 設定画面に版が出て、エラーにならない |

## してはいけないこと (ふだん使いのプロファイルで確かめるとき)

- コメントの書き込み・高評価・チャンネル登録など、アカウントに残る操作
- バックアップの読み込み (今の設定・チャンネルが置き換わる)。試すなら、先に書き出してから
