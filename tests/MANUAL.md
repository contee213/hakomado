# 手動確認の手順 (実際の YouTube を使うもの)

`npm test` は、YouTube に触らない部分 (チャンネルパック・視聴セットのコード・バックアップの検証・レイアウト・文言など) だけを試します。
YouTube のページの中で動く部分 (`content/`・枠の中のプレイヤー・ライブチャット) は、YouTube 側の変更で壊れやすく、
CI で動かすと不安定なので、大きく変えたときやリリースの前に、ここの手順で手で確かめます。

Chrome DevTools MCP (`.mcp.json` の `chrome-devtools`) を使うと、Claude Code から同じ手順を進められます。
ふだん使いのプロファイル (ログイン中の YouTube アカウント) につながるので、使う前に `CLAUDE.md` の注意を読んでください。

## 準備

1. Chrome で `chrome://inspect/#remote-debugging` を開き、「Allow remote debugging for this browser instance」をオンにする (DevTools MCP を使うとき。ブラウザを起動するたびに必要)
2. `chrome://extensions` で `extension/` を読み込む (読み込み済みなら再読み込み)
3. ツールバーのアイコンからマルチビュー画面を開く。service worker と画面のコンソールにエラーが出ていないこと

## 確かめること

| 何を | どうなればよいか |
| --- | --- |
| 枠に配信を入れる (URL・動画 ID・@チャンネル名) | 再生が始まり、枠の名前が出る |
| ライブチャット・弾幕 | 配信中の枠で、チャットが表示され、弾幕が流れる |
| 音の切り替え (クリック・ソロ・全部消音) | 選んだ枠だけ音が出る |
| アーカイブの同期再生 | 2 本以上で同期を ON にすると位置がそろい、一時停止・シークが全部に効く |
| レイアウトの切り替え・枠の入れ替え (ドラッグ) | 枠が 16:9 のまま並び替わり、再生が止まらない |
| 自動再生 (L) | 配信中のチャンネルが枠に入り、終わった配信が外れる |
| 🔗 視聴セットのコード | コードを作ってほかのタブで貼ると同じ並びになる。QR の画像を貼っても読める |
| 取り込み用リンク (`watch_videos?…&hakomado=名前`) | 開くと取り込み画面に切り替わり、再生リストとして入る |
| 広告 | 広告が流れたあとも、音・同期が元どおり効く |
| 新しい版の確認 | 設定画面に版が出て、エラーにならない |

## してはいけないこと (ふだん使いのプロファイルで確かめるとき)

- コメントの書き込み・高評価・チャンネル登録など、アカウントに残る操作
- バックアップの読み込み (今の設定・チャンネルが置き換わる)。試すなら、先に書き出してから
