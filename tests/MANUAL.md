# 手動確認の手順 (実際の YouTube を使うもの)

`npm test` は、YouTube に触らない部分 (チャンネルパック・視聴セットのコード・バックアップの検証・レイアウト・文言など) だけを試します。
`npm run test:e2e` (`e2e/`) は、マルチビュー画面のボタン・ダイアログ・ツアー・視聴セッションと、service worker のヘッダー書き換えの範囲を
本物のブラウザで試しますが、外への通信は止めているので、枠の中の YouTube は動きません。
YouTube のページの中で動く部分 (`content/`・枠の中のプレイヤー・ライブチャット) は、YouTube 側の変更で壊れやすく、
CI で動かすと不安定なので、大きく変えたときやリリースの前に、ここの手順で手で確かめます。

Chrome DevTools MCP (`.mcp.json` の `chrome-devtools`) を使うと、Claude Code から同じ手順を進められます。
ふだん使いのプロファイル (ログイン中の YouTube アカウント) につながるので、使う前に `CLAUDE.md` の注意を読んでください。

## 準備

1. Chrome で `chrome://inspect/#remote-debugging` を開き、「Allow remote debugging for this browser instance」をオンにする (DevTools MCP を使うとき。ブラウザを起動するたびに必要)
2. `chrome://extensions` で `extension/` を読み込む (読み込み済みなら再読み込み)
3. ツールバーのアイコンからマルチビュー画面を開く。service worker と画面のコンソールにエラーが出ていないこと

## 確かめること

| 何を | どうなればよいか |
| --- | --- |
| 枠に配信を入れる (URL・動画 ID・@チャンネル名) | 再生が始まり、枠の名前が出る |
| ライブチャット・弾幕 | 配信中の枠で、チャットが表示され、弾幕が流れる |
| 音の切り替え (クリック・ソロ・全部消音) | 選んだ枠だけ音が出る |
| 音の左右・音量 (ヘッドホンで) | 🎚 の L / R と「ℹ️ 枠の情報」の行の L / R のどちらでも片側から聞こえ、片方で変えるともう片方の点灯も変わる。枠の情報のタイトルを押すと YouTube の新しいタブで開く。そのあとも消音・ソロ・同期再生・広告のあとの音が今までどおり |
| 🎚 音量バランス (HAKO-54) | 声の大きさの違う配信 2〜3 本の音を出し、上部バーの 🎚 音量で「大きさをそろえる」を ON にすると、行に「測っています…」が出たあと「→ n%」に変わり、十数秒で聞こえる大きさが近づく。叫び声・一瞬の BGM で音量がゆらゆら動かない。1 枠をミュートにして戻しても音量が跳ねない。OFF でつまみの値だけに戻る。★ で主役にすると、ほかの音の出ている枠が 30% (「ほかの枠」のつまみ) になり、主役をミュートすると戻る。Twitch の枠でも同じ |
| アーカイブの同期再生 | 2 本以上で同期を ON にすると位置がそろい、一時停止・シークが全部に効く。画面の下に同期の調整の帯が出て、枠の並びがその分だけ縦に縮む (同期の調整パネルは無い。HAKO-48)。上部バーの ☰ で帯を出す / しまう。☰ か帯の ✕ で閉じると、次に自動で同期を始めても出ない (⏱ で ON にすると出る) |
| 同期グループ | 時間の違うコラボ 2 組 (例: `k6fQMwzFPoM` / `hdHVlPKYKwQ` と `inmap2iySzA` / `XcNobZGLrB0`) を 2×2 に並べて同期すると「2 組 (4 本)」と出て、帯にグループ 1・2、枠に色の線と番号が出る。グループごとの ⏸ はその組だけ止まる。帯で行を上下にドラッグして「同期しない」「グループ 3」(枠の無いグループ) に落とすと組み直される (1 本だけ残った枠は「重なる枠がありません」)。帯の見出しの「自動で分け直す」で、手で決めたグループが全部自動に戻る (手で決めたグループが無ければ押せない)。グループのつまみは、そのグループだけを動かす |
| 同期の調整の帯 | 行を押して選び ← → で補正が動く (0.1 秒。Shift 0.01、Ctrl 1。→ で波が右へ = 補正が減る)。行の波形を横にドラッグしても動く。補正の数字を押すと入力欄になる。↶ でその枠の補正がひとつずつ前に戻り、目盛りの左の「↺ 実際の時刻に戻す」でグループ全部が 0 に戻る。基準の行は 🔒 で、波形に覆いがかかり動かない。行は 1 行で、名前が長くても補正が大きくても列がずれない。拡大のスライダー・− / +・全体表示、目盛りの下のスクロールバーで見る範囲を動かせ、再生位置が右端を越えると範囲がめくれる |
| ✨ 自動補正 (帯のグループの見出し。今は音で合わせる) | コラボの 2 視点 (例: ガンギマリ姉妹 ラーメン屋 `k6fQMwzFPoM` 基準 / `hdHVlPKYKwQ`) で、話している場面から押す。測っている間 (最大 180 秒) 聞こえ方 (どの枠の音が出ているか) が変わらず、ボタンに進み具合が出る。ほかのグループも同時に測れる。35 秒を過ぎると、見出しの 2 段目が「途中の結果」になり、各行の波形に薄い「✨ −1.6x ○」と入れたあとの位置の水色の点線が出て、今の位置のまわり 30 秒へ拡大する。90 秒を過ぎて、どの枠も ◎ で 2 回以上同じ値が出ると「どの枠も ◎ になりました。ここで決めますか？」と出る (勝手には終わらない)。「ここで決める」か 180 秒で結果になり、「試す」で値が入って聞き比べられ、「決める」で終わる・「試す前に戻す」で ✨ の前に戻る。2 枠のときは 3 択 (真ん中が中間、およそ −1.60 秒。両側は −1.29 / −1.89 前後)。状態が変わってもボタンの位置は動かない。5 人のコラボ (`1TEs3v4hA78,xm0ZxpDQYJg,yuLlvdYwtng,oXfefvzpPwo,vnOhAveMDB0`、おかゆ基準) では、補正 0 から測って、おおよそ ぺこら −0.28 / ミオ +8.14〜8.25 / ヴィヴィ −5.7〜−5.8 / AZKi −63.3 になる。測っている間・計算中も、ほかの枠の再生や同期が止まらない。決められなかったときは「測り直す」が出る |
| ⏱ 開いて同期 (ライブラリの選択のバー) | 視聴履歴か最近の動画に、コラボの 2 視点 (例: `k6fQMwzFPoM` / `hdHVlPKYKwQ`) を出し、🤝 で選んで「⏱ 開いて同期」を押す。画面が閉じて空き枠に入り、⏱ が ON になって同期の調整の帯が出て、再生が始まると ✨ 自動補正が測り始める (ほかに押さなくてよい)。流れている枠は置き換わらない。関係の無いアーカイブ (時間帯の重ならないもの) を 2 本選んで押すと「同期できる組になりませんでした」と出る。3 視点以上のコラボに別の配信を 1 本混ぜて測ると、その行の波形が「✨ — 別の配信かも」になり、結果の「同期から外す」でその枠だけ同期から外れる。押したあとすぐ ⏸ で止めておくと、60 秒後に「再生が始まらないので ✨ 自動補正は始めていません」と出る (同期は ON のまま)。1 人だけ遅れて始まるコラボ (例: 2026-11-26 の森林脱出 `pz3vq2XOmwg` / `TyqCKSlacLc` / `SVEG2wGwxfE`) を配信の始めから開くと「…全部の配信が始まっているところまで進めました…」と出て、✨ が測り始める。動画・ショートを 2 本選んでも「⏱ 開いて同期」は出ない |
| 🎬 同時視聴 (帯のグループの見出しで 🎬 同時視聴) | 時間のずれた同時視聴のアーカイブ 2 本で、帯の各行の 🎬 の列の「🚩 開始位置」(または「⏲ 画面タイマー」+ Enter) を決めると、本編の同じ場面にそろい、目盛りとつまみが本編の時刻になって、波形が本編の時刻にそろって並ぶ。本編の位置を決めていない枠は「未定」で、波形の場所に案内が出る。ライブは「同期しない」から本編モードのグループへ行をドラッグして入れる。ライブ 1 本 + アーカイブ 1 本ではライブが基準になり、アーカイブがついてくる。🔗 共有のコードに「 ~!…」が付き、読み込むと本編モードで始まる。プレミア公開でない動画を行の 🎬 で本編にしてから共有すると、コードの最後に「,*番号」が付き、受け取った側でもその枠が 🎬 本編になる |
| レイアウトの切り替え・枠の入れ替え (ドラッグ) | 枠が 16:9 のまま並び替わり、再生が止まらない |
| Shift + 矢印キーで枠を動かす | 音が出ている枠がその方向の枠 (空き枠も) と入れ替わり、音はその枠についていく。続けて押すと同じ枠がさらに動く。その方向に枠が無ければ何もしない。音の出ている枠が無ければ何もしない。同期の調整の帯の行を選んでいるときの Shift + ← → は補正 (0.01 秒) で、枠は動かない |
| 自動再生 (L) | 配信中のチャンネルが枠に入り、終わった配信が外れる |
| 🔗 視聴セットのコード | コードを作ってほかのタブで貼ると同じ並びになる。QR の画像を貼っても読める |
| 取り込み用リンク (`watch_videos?…&hakomado=名前`) | 開くと取り込み画面に切り替わり、再生リストとして入る |
| スクリーンショット (Alt+Shift+S。chrome://extensions/shortcuts で確かめる) | マルチビュー画面のタブで押すと、確認なしで枠の並び (上部バーは除く) が `hakomado-日付-時刻.png` で保存され、クリップボードにも入る (ペイントなどに貼れる)。動画・弾幕も写り、マウスが乗っていた枠の操作バーとカーソルは写らない。YouTube のタブで押しても何も起きない |
| 広告 | 広告が流れたあとも、音・同期が元どおり効く |
| 新しい版の確認 | 設定画面に版が出て、エラーにならない |

## してはいけないこと (ふだん使いのプロファイルで確かめるとき)

- コメントの書き込み・高評価・チャンネル登録など、アカウントに残る操作
- バックアップの読み込み (今の設定・チャンネルが置き換わる)。試すなら、先に書き出してから
